# 01. #define для константы

**Сложность:** супер простая

**Файл с решением:** [01_define_const.c](./01_define_const.c)

## Описание задачи

С помощью `#define MAX_USERS 100` определите константу и выведите её через `printf`.

## Описание решения

`#define X V` — текстовая замена на этапе препроцессора: каждое вхождение `X` заменяется на `V` до компиляции. Поэтому это не переменная, занимающая память, а просто литерал в коде.

## Примеры

**Пример 1.**

Вывод:
```
MAX_USERS = 100
```
