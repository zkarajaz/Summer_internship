# 04. Предопределённые макросы __FILE__ и __LINE__

**Сложность:** супер простая

**Файл с решением:** [04_file_line.c](./04_file_line.c)

## Описание задачи

Выведите имя текущего файла и номер строки, где находится `printf`.

## Описание решения

`__FILE__` подставляется как строковый литерал с именем исходного файла, `__LINE__` — как целочисленный номер строки. Они полезны для отладочного логирования.

## Примеры

**Пример 1.**

Вывод:
```
file=04_file_line.c line=5
```
