# 05. #include: системный vs пользовательский

**Сложность:** супер простая

**Файл с решением:** [05_include_user_vs_system.c](./05_include_user_vs_system.c)

## Описание задачи

Создайте свой заголовок `greet.h` с прототипом функции и используйте `#include <stdio.h>` (стандартный, угловые скобки) и `#include "greet.h"` (свой, кавычки) в одной программе. Реализация `greet` лежит в `greet.c`.

## Описание решения

`<...>` ищет файл в системных каталогах (заданных компилятору), `"..."` сначала в каталоге исходника, потом в системных. Свои заголовки подключайте кавычками.

## Примеры

**Пример 1.**

```
$ cc 05_include_user_vs_system.c greet.c -o demo && ./demo
hello from greet.c
```
