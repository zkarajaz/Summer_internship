# 07. Сборка из нескольких .c файлов

**Сложность:** простая

**Файл с решением:** [07_multifile_build.c](./07_multifile_build.c)

## Описание задачи

Программа состоит из `07_multifile_build.c` (main), `add.c` (определение `int add(int,int)`) и `add.h` (прототип). Каждый `.c` компилируется в `.o`, потом линкуются.

## Описание решения

Этапы: препроцессинг → компиляция (.c → .o) → линковка (.o + .o → исполняемый). Заголовок `add.h` нужен, чтобы `main` знал прототип `add`, а определение лежит в `add.c`.

## Примеры

**Пример 1.**

```
$ cc 07_multifile_build.c add.c -o app && ./app
2 + 3 = 5
```
