# 08. Передача макроса через -D

**Сложность:** простая

**Файл с решением:** [08_dmacro_from_cli.c](./08_dmacro_from_cli.c)

## Описание задачи

Напишите программу, которая печатает строку `VERSION`. Не определяйте `VERSION` в коде — передайте его при сборке через ключ `-D`.

## Описание решения

Ключ `-Dname=value` передаёт макрос компилятору, эквивалент `#define`. Так удобно держать в коде версии, флаги сборки и параметры тестирования вне исходников.

## Примеры

**Пример 1.**

```
$ cc -DVERSION='"1.2.3"' 08_dmacro_from_cli.c -o demo && ./demo
version: 1.2.3
```

**Пример 2.**

```
$ cc 08_dmacro_from_cli.c -o demo && ./demo
version: unset
```
