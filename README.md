<h1>1. Классификация моделей систем; место непрерывных динамических систем; понижение порядка ОДУ; примеры (распад, маятник, задача $N$ тел); прямая и обратная задача</h1>
<h2>Зачем это нужно?</h2>
<p>Вычислительная математика занимается тем, что даёт реальные числа в задачах, которые невозможно (или непрактично) решить вручную. Чтобы понимать, какой численный метод подходит для какой задачи, надо сначала научиться <strong>классифицировать сами задачи</strong>. Этот вопрос — обзорный, он задаёт «карту местности» курса.</p>
<h2>Что такое модель и какие они бывают</h2>
<p><strong>Модель</strong> — это математическое описание системы (физической, биологической, экономической — какой угодно). Модели отличаются по нескольким признакам, и каждый признак влияет на то, какие методы применимы.</p>
<ol>
<li>
<p><strong>Детерминированная</strong> vs <strong>стохастическая.</strong></p>
<ul>
<li>Детерминированная: одни и те же входные данные всегда дают один и тот же результат. Пример: брошенный камень падает по конкретной траектории, заданной законами Ньютона.</li>
<li>Стохастическая: результат содержит случайность. Пример: цена акции через час — мы можем описать её как случайную величину.</li>
</ul>
</li>
<li>
<p><strong>С непрерывным временем</strong> vs <strong>с дискретным временем.</strong></p>
<ul>
<li>Непрерывное: $t$ — действительное число, состояние системы $y(t)$ определено в каждый момент. Описывается ОДУ $\dot y = f(t, y)$.</li>
<li>Дискретное: $t = 0, 1, 2, \ldots$, состояние меняется скачками. Описывается рекуррентой $y_{n+1} = g(y_n)$.</li>
</ul>
</li>
<li>
<p><strong>С сосредоточенными</strong> vs <strong>распределёнными параметрами.</strong></p>
<ul>
<li>Сосредоточенные: состояние — конечный набор чисел (вектор). Описываются ОДУ.</li>
<li>Распределённые: состояние — функция координат (например, температура в каждой точке стержня). Описываются уравнениями в частных производных (УрЧП).</li>
</ul>
</li>
<li>
<p><strong>Линейные</strong> vs <strong>нелинейные</strong>, <strong>автономные</strong> ($f$ не зависит явно от $t$) vs <strong>неавтономные</strong>, <strong>консервативные</strong> (сохраняется энергия) vs <strong>диссипативные</strong>.</p>
</li>
</ol>
<h2>Что такое непрерывная динамическая система</h2>
<p><strong>Непрерывная динамическая система</strong> — это математическая модель в виде системы обыкновенных дифференциальных уравнений первого порядка:
$$\dot{\mathbf{y}}(t) = \mathbf{f}(t, \mathbf{y}(t)), \qquad \mathbf{y}(t_0) = \mathbf{y}_0,$$
где $\mathbf{y}(t) \in \mathbb{R}^n$ — вектор состояния системы (фазовая точка), $\mathbf{f}$ — заданное векторное поле, $\mathbf{y}_0$ — начальное состояние. Переменная $t$ обычно — время.</p>
<p><strong>Место в классификации:</strong> детерминированная, с непрерывным временем, с сосредоточенными параметрами. Такие системы стоят в центре нашего курса.</p>
<h2>Понижение порядка системы ОДУ</h2>
<p><strong>Зачем.</strong> Все теоремы и численные методы в курсе сформулированы для систем уравнений <strong>первого порядка</strong>. Но в физике часто естественно возникают уравнения второго (и выше) порядка — например, второй закон Ньютона $m\ddot{\mathbf{r}} = \mathbf{F}$ содержит $\ddot{\mathbf{r}}$, а не $\dot{\mathbf{r}}$. Чтобы применить машинерию первого порядка, надо <strong>свести</strong> уравнение высокого порядка к системе первого.</p>
<p><strong>Как.</strong> Пусть имеем уравнение $n$-го порядка:
$$y^{(n)} = F(t, y, y', y'', \ldots, y^{(n-1)}).$$</p>
<p><strong>Трюк:</strong> вводим $n$ новых переменных-«ярлыков»:
$$z_1 = y, \quad z_2 = y', \quad z_3 = y'', \quad \ldots, \quad z_n = y^{(n-1)}.$$</p>
<p>Тогда первые $n-1$ уравнений получаются автоматически из определений:
$$\dot z_1 = z_2, \quad \dot z_2 = z_3, \quad \ldots, \quad \dot z_{n-1} = z_n,$$
а последнее — из исходного уравнения, в котором $y^{(n)} = \dot z_n$:
$$\dot z_n = F(t, z_1, z_2, \ldots, z_n).$$</p>
<p>Получили систему <strong>$n$ уравнений первого порядка</strong> для вектора $\mathbf{z} = (z_1, \ldots, z_n)$. Любое уравнение или система уравнений высокого порядка приводится к такому виду.</p>
<p><strong>Пример</strong> (понижение порядка для маятника). Уравнение $\ddot\varphi = -\frac{g}{\ell}\sin\varphi$ — второго порядка. Вводим $z_1 = \varphi$, $z_2 = \dot\varphi$. Получаем систему:
$$\dot z_1 = z_2, \qquad \dot z_2 = -\frac{g}{\ell}\sin z_1.$$
Это уже система первого порядка для двумерного вектора $(z_1, z_2)$.</p>
<h2>Примеры динамических систем</h2>
<h3>Пример 1. Радиоактивный распад</h3>
<p><strong>Физика.</strong> Атомы радиоактивного вещества распадаются независимо друг от друга, вероятность распада одного атома за единицу времени постоянна. Если $N(t)$ — число нераспавшихся атомов в момент $t$, то скорость распада пропорциональна числу атомов:
$$\dot N(t) = -\lambda N(t), \qquad N(0) = N_0,$$
где $\lambda &gt; 0$ — постоянная распада, $N_0$ — начальное число атомов. Знак минус — потому что число атомов <strong>убывает</strong>.</p>
<p><strong>Решение</strong> (находится точно): $N(t) = N_0 e^{-\lambda t}$.</p>
<p><strong>Прямая задача:</strong> даны $\lambda$ и $N_0$ — найти $N(t)$ для всех $t &gt; 0$. То есть <strong>по параметрам модели предсказать поведение</strong>.</p>
<p><strong>Обратная задача:</strong> известны измерения $N(t_1), N(t_2), \ldots$ (например, экспериментально посчитали число распадов в разные моменты времени) — определить $\lambda$ и $N_0$. То есть <strong>по поведению восстановить параметры</strong>. Именно так делают радиоуглеродный анализ для датировки артефактов.</p>
<h3>Пример 2. Идеальный маятник</h3>
<p><strong>Физика.</strong> Точечная масса на невесомом стержне длины $\ell$ в поле тяжести $g$, без трения. Угол отклонения от вертикали $\varphi(t)$ удовлетворяет:
$$\ddot\varphi + \frac{g}{\ell}\sin\varphi = 0.$$
В векторной форме (после понижения порядка) получаем систему для $(\varphi, \omega = \dot\varphi)$:
$$\dot\varphi = \omega, \qquad \dot\omega = -\frac{g}{\ell}\sin\varphi.$$
Это автономная система: $f$ не зависит явно от $t$.</p>
<p><strong>Прямая задача:</strong> даны $g/\ell$, $\varphi(0)$, $\omega(0)$ — рассчитать траекторию. Точного аналитического решения для произвольных амплитуд нет (только для малых углов, где $\sin\varphi \approx \varphi$ — обычное гармоническое колебание).</p>
<p><strong>Обратная задача:</strong> наблюдая за периодом колебаний (или за траекторией), определить $g/\ell$. Это, например, гравиметрия: при известной длине стержня период колебаний даёт значение $g$ в данной точке Земли (а $g$ слегка зависит от широты, высоты и плотности подстилающих пород — этим пользуются геологи).</p>
<h3>Пример 3. Гравитационная задача $N$ тел</h3>
<p><strong>Физика.</strong> $N$ материальных точек с массами $m_i$ движутся в собственном поле тяготения. Радиус-вектор $i$-го тела — $\mathbf{r}_i(t) \in \mathbb{R}^3$. По второму закону Ньютона и закону всемирного тяготения:
$$m_i,\ddot{\mathbf{r}}<em>i = G \sum</em>{j \ne i} \frac{m_i m_j (\mathbf{r}_j - \mathbf{r}_i)}{|\mathbf{r}_j - \mathbf{r}_i|^3}, \qquad i = 1, \ldots, N.$$</p>
<p>После понижения порядка (вводим скорости $\mathbf{v}_i = \dot{\mathbf{r}}_i$) получаем <strong>систему из $6N$ уравнений первого порядка</strong> (по 3 координаты + 3 компоненты скорости на каждое тело).</p>
<p><strong>Прямая задача:</strong> даны массы и начальные положения и скорости — рассчитать траектории. При $N=2$ есть точное решение (кеплеровские орбиты — эллипсы, параболы, гиперболы). При $N \ge 3$ в общем случае точного решения нет, нужны численные методы.</p>
<p><strong>Обратная задача:</strong> по наблюдаемым траекториям планет восстановить их массы (и проверить закон тяготения). Так Леверье и Адамс в 1846 году по аномалиям движения Урана предсказали существование Нептуна, а затем его обнаружили в предсказанном месте.</p>
<h2>Что говорить на экзамене (резюме)</h2>
<blockquote>
<p><strong>Модели систем</strong> делятся по: детерминированности (детерм./стох.), времени (непр./дискр.), параметрам (сосред./распред.), линейности, автономности, консервативности.</p>
<p><strong>Непрерывные динамические системы</strong> — детерминированные модели с непрерывным временем и сосредоточенными параметрами; описываются ОДУ $\dot{\mathbf{y}} = \mathbf{f}(t, \mathbf{y})$, $\mathbf{y}(t_0) = \mathbf{y}_0$.</p>
<p><strong>Понижение порядка:</strong> уравнение $y^{(n)} = F(t, y, \ldots, y^{(n-1)})$ заменяется системой первого порядка через введение $z_k = y^{(k-1)}$, $k=1,\ldots,n$.</p>
<p><strong>Примеры:</strong></p>
<ul>
<li><strong>Распад:</strong> $\dot N = -\lambda N$. Прямая — найти $N(t)$ по $\lambda$, $N_0$. Обратная — определить $\lambda$ по измерениям.</li>
<li><strong>Маятник:</strong> $\ddot\varphi + (g/\ell)\sin\varphi = 0$. Прямая — найти траекторию. Обратная — определить $g/\ell$ по периоду.</li>
<li><strong>Задача $N$ тел:</strong> второй закон Ньютона + всемирное тяготение, $6N$ уравнений первого порядка. Прямая — рассчитать орбиты. Обратная — определить массы по наблюдениям (так открыли Нептун).</li>
</ul>
</blockquote>

<h1>2. Задача Коши; лемма Асколи; теорема Коши-Пеано (с доказательством); теорема Пикара-Линделёфа</h1>
<blockquote>
<p><strong>Источник:</strong> Коддингтон, Левинсон, <em>Теория обыкновенных дифференциальных уравнений</em>, гл. I, §1, стр. 14–20. Содержание сверено по присланным скриншотам.</p>
</blockquote>
<h2>Зачем это нужно?</h2>
<p>Прежде чем что-то численно решать, надо убедиться, что <strong>решение вообще существует</strong>. Иначе мы будем считать ерунду. И если решений несколько (как может быть для нелинейных задач), численный метод выберет какое-то одно из них — и неясно, какое именно. Поэтому теоремы <strong>существования</strong> и <strong>единственности</strong> — это фундамент, на котором стоит вся последующая теория.</p>
<h2>Что такое задача Коши</h2>
<p><strong>Задача Коши</strong> — это вот такая постановка. Дано векторное поле $\mathbf{f}: D \to \mathbb{R}^n$ (где $D \subset \mathbb{R} \times \mathbb{R}^n$ — некоторая область), точка $(\tau, \xi) \in D$. Найти функцию $\varphi(t)$, определённую на каком-то интервале вокруг $\tau$, такую что:
$$\dot\varphi(t) = \mathbf{f}(t, \varphi(t)) \quad \text{(уравнение)} \qquad \text{и} \qquad \varphi(\tau) = \xi \quad \text{(начальное условие)}.$$</p>
<p>Сокращённо обозначим уравнение $\dot x = f(t, x)$ как <strong>(У)</strong>, а пару «уравнение + начальное условие» — как задачу Коши.</p>
<p><strong>Геометрический смысл.</strong> В каждой точке $(t, x)$ области $D$ векторное поле $f$ задаёт «направление»: касательная к решению, проходящему через эту точку, должна быть направлена как $f(t, x)$. Решение задачи Коши — это кривая, выходящая из точки $(\tau, \xi)$ и в каждой своей точке имеющая нужную касательную.</p>
<p><strong>Эквивалентная интегральная форма.</strong> Задача Коши эквивалентна интегральному уравнению:
$$\varphi(t) = \xi + \int_\tau^t f(s, \varphi(s)),ds.$$
В одну сторону: продифференцируем — получим $\dot\varphi = f(t, \varphi)$, и при $t = \tau$ интеграл нулевой, значит $\varphi(\tau) = \xi$. В другую: проинтегрируем уравнение по $s$ от $\tau$ до $t$ — и получим интегральную форму.</p>
<p><strong>Зачем нам интегральная форма.</strong> В интеграле подынтегральная функция может быть просто непрерывной, без необходимости дифференцируемости. Это удобно для теоретических построений: легче получить решение как <strong>предел</strong> последовательности приближений.</p>
<h2>Лемма Асколи (Арцела-Асколи) — без доказательства</h2>
<p><strong>Зачем эта лемма.</strong> Чтобы доказать, что задача Коши имеет решение, мы построим <strong>последовательность</strong> приближённых решений $\varphi_n$ и захотим взять её предел. Но не любая последовательность непрерывных функций имеет сходящуюся подпоследовательность! Лемма Асколи говорит, при каких условиях это возможно.</p>
<p><strong>Два понятия для семейства функций $F$:</strong></p>
<ol>
<li>
<p><strong>Равномерная ограниченность</strong> — существует одно общее число $M$ такое, что $|f(t)| \le M$ для всех $f \in F$ и всех $t$ из интервала. То есть весь набор значений всех функций умещается в одну полоску.</p>
</li>
<li>
<p><strong>Равностепенная непрерывность</strong> — для каждого $\varepsilon &gt; 0$ существует <strong>одно общее</strong> $\delta &gt; 0$ такое, что для всех $f \in F$:
$$|t_1 - t_2| &lt; \delta ;;\Longrightarrow;; |f(t_1) - f(t_2)| &lt; \varepsilon.$$
То есть все функции «гладкие в одинаковой степени». Обычная (поточечная) непрерывность каждой функции — это то же самое, но $\delta$ может зависеть от функции; здесь требуется, чтобы $\delta$ работало сразу для всех.</p>
</li>
</ol>
<p><strong>Лемма (Асколи).</strong> Если $F$ — равномерно ограниченное и равностепенно непрерывное семейство функций на конечном интервале $I$, то из него можно выделить последовательность ${f_n}$, <strong>сходящуюся равномерно</strong> на $I$.</p>
<p>(Идея доказательства: на множестве рациональных точек интервала (а оно счётное!) последовательно строится «диагональная» подпоследовательность, сходящаяся в каждой рациональной точке. Затем, благодаря равностепенной непрерывности, сходимость распространяется на все точки и оказывается равномерной. Подробное доказательство — в книге, стр. 14.)</p>
<h2>Теорема Коши-Пеано (теорема 1.2 в книге, стр. 14)</h2>
<p><strong>Формулировка.</strong> Пусть $f$ непрерывна в прямоугольнике
$$R = {(t, x):; |t - \tau| \le a,; |x - \xi| \le b}, \qquad M = \max_R |f|, \qquad \alpha = \min(a, b/M).$$
Тогда <strong>существует</strong> решение $\varphi \in C^1$ задачи Коши $\dot x = f(t, x)$, $x(\tau) = \xi$, определённое на интервале $|t - \tau| \le \alpha$.</p>
<p><strong>Что значит $\alpha = \min(a, b/M)$.</strong> На отрезке времени длины $\alpha$ функция $\varphi$ за счёт условия $|\dot\varphi| = |f(t, \varphi)| \le M$ может уйти от $\xi$ не дальше, чем на $M\alpha \le b$. То есть $\varphi$ гарантированно остаётся в прямоугольнике $R$, где $f$ определена и непрерывна. Это технический трюк, чтобы решение «не убежало» из области определения $f$.</p>
<p><strong>Зачем такая теорема нужна.</strong> Она говорит: если правая часть просто непрерывна (без всяких дополнительных условий), решение заведомо существует. Это очень слабое требование — почти любая встречающаяся на практике $f$ ему удовлетворяет.</p>
<h2>Доказательство теоремы Коши-Пеано (по книге, стр. 14–15)</h2>
<p>Доказательство строится по схеме <strong>«построить последовательность приближённых решений → доказать равностепенную непрерывность → применить лемму Асколи → перейти к пределу»</strong>.</p>
<p><strong>Шаг 1. Что такое $\varepsilon$-приближённое решение</strong> (из теоремы 1.1, на которую ссылка). Это кусочно-дифференцируемая функция $\varphi_n$ на $[\tau-a, \tau+a]$ такая, что:</p>
<ul>
<li>$\varphi_n(\tau) = \xi$;</li>
<li>$|\dot\varphi_n(t) - f(t, \varphi_n(t))| \le \varepsilon$ почти везде (в каждой точке, где производная существует).</li>
</ul>
<p>Грубо говоря, $\varphi_n$ — это «ломаная Эйлера»: на маленьких отрезках $\varphi_n$ — линейная функция с наклоном $\approx f$, поэтому она почти удовлетворяет уравнению. По теореме 1.1 (которая в книге доказывается до 1.2) для любого $\varepsilon &gt; 0$ такое приближённое решение есть.</p>
<p><strong>Шаг 2. Берём последовательность $\varepsilon_n \to 0$</strong> и для каждого $\varepsilon_n$ выбираем $\varepsilon_n$-приближённое решение $\varphi_n$. Получили последовательность функций ${\varphi_n}$.</p>
<p><strong>Шаг 3. Эти функции «гладкие с одинаковой константой».</strong> Из определения приближённого решения и из факта $|f| \le M$ на $R$ выводится оценка:
$$|\varphi_n(t) - \varphi_n(\tilde t)| \le M,|t - \tilde t| \qquad (1.5)$$
для любых $t, \tilde t$ в области определения. Это значит: семейство ${\varphi_n}$ <strong>равностепенно непрерывно</strong> (с $\delta = \varepsilon/M$, общим для всех $n$).</p>
<p><strong>Шаг 4. Семейство равномерно ограничено.</strong> Из (1.5) при $\tilde t = \tau$, $\varphi_n(\tau) = \xi$:
$$|\varphi_n(t) - \xi| \le M|t - \tau| \le M\alpha \le b,$$
поэтому $|\varphi_n(t)| \le |\xi| + b$ — общая граница, не зависящая от $n$.</p>
<p><strong>Шаг 5. Применяем лемму Асколи.</strong> Из ${\varphi_n}$ можно выделить подпоследовательность ${\varphi_{n_k}}$, <strong>равномерно сходящуюся</strong> на $[\tau-\alpha, \tau+\alpha]$ к некоторой функции $\varphi$. Эта $\varphi$ непрерывна (как равномерный предел непрерывных), и из (1.5) сама удовлетворяет $|\varphi(t) - \varphi(\tilde t)| \le M|t - \tilde t|$.</p>
<p><strong>Шаг 6. Покажем, что $\varphi$ — решение.</strong> Запишем $\varphi_n$ в интегральной форме. Введём $\Delta_n(t) = \dot\varphi_n(t) - f(t, \varphi_n(t))$ там, где производная существует, и $\Delta_n(t) = 0$ в остальных точках. Тогда:
$$\varphi_n(t) = \xi + \int_\tau^t \big[f(s, \varphi_n(s)) + \Delta_n(s)\big],ds. \qquad (1.6)$$
По определению приближённого решения $|\Delta_n(s)| \le \varepsilon_n$, поэтому $\int \Delta_n \to 0$. А благодаря <strong>равномерной непрерывности</strong> $f$ на $R$ (она компактна) и равномерной сходимости $\varphi_{n_k} \to \varphi$ имеем $f(s, \varphi_{n_k}(s)) \to f(s, \varphi(s))$ равномерно. Заменяя в (1.6) $n$ на $n_k$ и переходя к пределу при $k \to \infty$:
$$\varphi(t) = \xi + \int_\tau^t f(s, \varphi(s)),ds. \qquad (1.7)$$</p>
<p><strong>Шаг 7. Завершение.</strong> При $t = \tau$ интеграл нулевой, значит $\varphi(\tau) = \xi$. Подынтегральная функция $f(t, \varphi(t))$ непрерывна, значит интеграл — функция класса $C^1$, и продифференцировав (1.7), получаем $\dot\varphi(t) = f(t, \varphi(t))$. Итого: $\varphi \in C^1$, удовлетворяет уравнению и начальному условию. Теорема доказана. $\blacksquare$</p>
<p><strong>Замечание о неединственности.</strong> Книга специально подчёркивает: метод доказательства даёт <strong>подпоследовательность</strong>, а не всю последовательность приближённых решений. Это связано с тем, что у задачи Коши с непрерывной (но не липшицевой) $f$ может быть <strong>несколько решений</strong>! Классический пример: $\dot x = x^{1/3}$ при $x(0) = 0$ имеет бесконечно много решений: $x(t) = 0$ и $x_c(t) = \big(\tfrac{2(t-c)}{3}\big)^{3/2}$ для любого $c \ge 0$ (см. книгу, стр. 16).</p>
<h2>Теорема Пикара-Линделёфа — без доказательства</h2>
<blockquote>
<p><strong>Замечание.</strong> Преподаватель указывает на «теорему 3.1» — это теорема существования и единственности при условии Липшица. В присланных мной скриншотах это <strong>теорема 2.3, стр. 19</strong> (вариант для прямоугольника). Статья 3.1, видимо, в §3 главы I (его в скриншотах нет), но математическое содержание то же.</p>
</blockquote>
<p><strong>Условие Липшица.</strong> Функция $f$ удовлетворяет условию Липшица по $x$ в области $D$, если существует константа $k &gt; 0$ такая, что для всех $(t, x_1)$, $(t, x_2)$ из $D$:
$$|f(t, x_1) - f(t, x_2)| \le k,|x_1 - x_2|.$$
<strong>Содержательно</strong> это означает, что функция «не слишком крутая» по $x$. Достаточное условие — существование и непрерывность производной $\partial f/\partial x$ на компакте (см. книгу, стр. 17). Условие Липшица <strong>сильнее</strong> просто непрерывности.</p>
<p><strong>Теорема (Пикара-Линделёфа, в форме теоремы 2.3 книги, стр. 19).</strong> Пусть $f$ непрерывна и удовлетворяет условию Липшица по $x$ в прямоугольнике
$$R: ;;|t - \tau| \le a, ;;|x - \xi| \le b, \qquad M = \max_R |f|, \qquad \alpha = \min(a, b/M).$$
Тогда <strong>существует и единственно</strong> решение $\varphi \in C^1$ задачи Коши $\dot x = f(t, x)$, $x(\tau) = \xi$ на интервале $|t - \tau| \le \alpha$.</p>
<p><strong>Что добавляется по сравнению с Пеано:</strong> 1) гарантия <strong>единственности</strong> решения; 2) можно доказать сходимость метода последовательных приближений Пикара:
$$\varphi^{(0)}(t) \equiv \xi, \qquad \varphi^{(k+1)}(t) = \xi + \int_\tau^t f(s, \varphi^{(k)}(s)),ds.$$
Эти приближения сходятся к решению равномерно (а не подпоследовательность из них) — это и есть конструктивный «метод Пикара». В книге это разбирается в §3 главы I.</p>
<p><strong>Идея доказательства единственности</strong> (теорема 2.2, стр. 18): если $\varphi_1, \varphi_2$ — два решения с одинаковым начальным условием, то их разность удовлетворяет интегральному неравенству Гронуолла (по сути, неравенство (2.2) книги), из которого следует, что разность тождественно равна нулю.</p>
<h2>Что говорить на экзамене</h2>
<blockquote>
<p><strong>Задача Коши:</strong> $\dot x = f(t, x)$, $x(\tau) = \xi$. Эквивалентна интегральному уравнению $\varphi(t) = \xi + \int_\tau^t f(s, \varphi(s)),ds$.</p>
<p><strong>Лемма Асколи:</strong> равномерно ограниченное и равностепенно непрерывное семейство функций на конечном интервале содержит равномерно сходящуюся последовательность. (Доказательство — диагональным процессом по рациональным точкам; не требуется на экзамене.)</p>
<p><strong>Теорема Коши-Пеано (1.2):</strong> $f \in C(R) \Rightarrow$ решение $\exists$ на $|t-\tau| \le \alpha = \min(a, b/M)$.</p>
<p><em>Схема доказательства:</em> строим $\varepsilon_n$-приближённые решения (ломаные Эйлера), доказываем их равностепенную непрерывность с константой $M$ через $|f| \le M$, применяем лемму Асколи — выделяем равномерно сходящуюся подпоследовательность $\varphi_{n_k} \to \varphi$. Записываем $\varphi_{n_k}$ в интегральной форме $\varphi_{n_k}(t) = \xi + \int(f(\cdot, \varphi_{n_k}) + \Delta_{n_k})$; переходим к пределу — получаем $\varphi(t) = \xi + \int f(s, \varphi(s)),ds$, что эквивалентно уравнению с условием $\varphi(\tau) = \xi$.</p>
<p><strong>Теорема Пикара-Линделёфа (2.3 / 3.1):</strong> $f \in C(R)$ + Липшиц по $x$ $\Rightarrow$ решение $\exists$ и <strong>единственно</strong> на $|t - \tau| \le \alpha$. Доказывается методом последовательных приближений Пикара.</p>
</blockquote>

<h1>3. Общий вид и классификация методов Рунге-Кутты; таблицы Бутчера; методы Эйлера, Хойна, средней точки</h1>
<blockquote>
<p><strong>Источники:</strong> Хайрер-Нёрсетт-Ваннер, гл. II.1 «The First Runge-Kutta Methods», стр. 132–141 (общая формулировка, обсуждение методов 4-го порядка, оптимальные формулы); Wikipedia, "List of Runge–Kutta methods" (явные формулы методов 1–2 порядка).</p>
</blockquote>
<h2>Зачем это нужно?</h2>
<p>Мы хотим <strong>численно</strong> решать задачу Коши $\dot y = f(t, y)$, $y(t_0) = y_0$. Идея: заменить непрерывное время дискретной сеткой $t_0, t_1 = t_0 + h, t_2 = t_0 + 2h, \ldots$ и на каждом шаге, зная $y_n \approx y(t_n)$, считать приближение $y_{n+1} \approx y(t_{n+1})$. Это <strong>одношаговый метод</strong> — для следующего значения нужна только последняя точка.</p>
<p>Самый простой одношаговый метод — Эйлер: «иди вдоль направления $f(t_n, y_n)$ шаг $h$». Но он неточный. Методы Рунге-Кутты — это семейство улучшений идеи Эйлера, которые на одном шаге вычисляют $f$ в нескольких промежуточных точках и <strong>умно усредняют</strong> результаты.</p>
<h2>Главная идея</h2>
<p><strong>Точное решение</strong> удовлетворяет:
$$y(t_n + h) = y(t_n) + \int_{t_n}^{t_n + h} f(t, y(t)),dt.$$
Интеграл точно вычислить нельзя (мы не знаем $y(t)$). <strong>Идея РК:</strong> оценить интеграл квадратурой по нескольким точкам внутри $[t_n, t_n + h]$. Но в этих точках мы тоже не знаем $y$ — поэтому и его приходится оценивать! Так возникают <strong>стадии</strong>.</p>
<h2>Общая формула $s$-стадийного метода РК</h2>
<p>На каждом шаге для перехода от $y_n$ к $y_{n+1}$ выполняем $s$ вспомогательных вычислений (стадий), каждое — это вычисление $f$ в некоторой промежуточной точке:</p>
<p>$$\boxed{;
k_i = f!\left(t_n + c_i h,;; y_n + h\sum_{j=1}^{s} a_{ij}, k_j\right), \qquad i = 1, 2, \ldots, s.
;}$$</p>
<p>Затем итоговое значение:
$$\boxed{; y_{n+1} = y_n + h\sum_{i=1}^{s} b_i, k_i. ;}$$</p>
<p><strong>Расшифровка:</strong></p>
<ul>
<li>$h$ — шаг по времени;</li>
<li>$c_i \in [0, 1]$ — «времена» стадий внутри шага: $c_1 h, c_2 h, \ldots$ — это смещения от $t_n$;</li>
<li>$a_{ij}$ — коэффициенты, показывающие, как промежуточные значения $k_j$ влияют на оценку $y$ в точке $t_n + c_i h$, использующуюся для $i$-й стадии;</li>
<li>$b_i$ — веса, с которыми $k_i$ участвуют в итоговом усреднении.</li>
</ul>
<p><strong>Условие согласованности:</strong> $\sum_j a_{ij} = c_i$ — обеспечивает, что для автономной системы оба способа интерпретации (через $c_i$ и через $a_{ij}$) совпадают.</p>
<p><strong>Для метода 1-го порядка</strong> обязательно: $\sum_i b_i = 1$.</p>
<h2>Таблица Бутчера</h2>
<p>Чтобы не выписывать все коэффициенты текстом, используют компактную <strong>таблицу Бутчера</strong>:</p>
<p>$$\begin{array}{c|cccc}
c_1 &amp; a_{11} &amp; a_{12} &amp; \cdots &amp; a_{1s} \
c_2 &amp; a_{21} &amp; a_{22} &amp; \cdots &amp; a_{2s} \
\vdots &amp; \vdots &amp; \vdots &amp; \ddots &amp; \vdots \
c_s &amp; a_{s1} &amp; a_{s2} &amp; \cdots &amp; a_{ss} \
\hline
&amp; b_1 &amp; b_2 &amp; \cdots &amp; b_s
\end{array}$$</p>
<p>Слева — вектор $\mathbf{c}$, в центре — матрица $A$, снизу — вектор $\mathbf{b}^T$. Это <strong>полное описание</strong> метода: сравнить два метода — значит сравнить их таблицы.</p>
<h2>Классификация</h2>
<p>Глядя на матрицу $A$, методы делят на:</p>
<ol>
<li>
<p><strong>Явные (ERK, Explicit Runge-Kutta):</strong> $A$ — строго нижнетреугольная, то есть $a_{ij} = 0$ при $j \ge i$. Это значит, что $k_1$ зависит только от уже известного $y_n$, $k_2$ — от $y_n$ и $k_1$, $k_3$ — от $y_n, k_1, k_2$, и т.д. <strong>Каждое $k_i$ вычисляется по уже найденным.</strong> Никаких уравнений решать не надо.</p>
</li>
<li>
<p><strong>Полностью неявные (FIRK):</strong> $A$ — произвольная. Тогда $k_i$ образуют <strong>связанную систему уравнений</strong> (нелинейных, если $f$ нелинейна), которую надо решать на каждом шаге.</p>
</li>
<li>
<p><strong>Диагонально-неявные (DIRK):</strong> $A$ — нижнетреугольная, но с ненулевыми элементами на диагонали ($a_{ii} \ne 0$). Тогда каждое $k_i$ ищется из своего скалярного нелинейного уравнения по $k_1, \ldots, k_{i-1}$, найденным на предыдущих стадиях. Дешевле, чем FIRK.</p>
</li>
<li>
<p><strong>Вложенные (embedded):</strong> в таблице вместо одного вектора $\mathbf{b}$ выписывают два — $\mathbf{b}$ и $\hat{\mathbf{b}}$, дающих методы разных порядков. Это нужно для оценки локальной ошибки (см. вопрос 6).</p>
</li>
</ol>
<p><strong>По числу стадий и порядку:</strong> метод $s$-стадийный, порядка $p$ означает: на одном шаге вычисляется $f$ ровно $s$ раз, а локальная ошибка усечения — $O(h^{p+1})$.</p>
<h2>Метод Эйлера (явный, 1-стадийный, 1-го порядка)</h2>
<p>Самый простой метод. Идея: $y(t_n + h) \approx y(t_n) + h \dot y(t_n) = y(t_n) + h f(t_n, y(t_n))$.</p>
<p>Формула:
$$y_{n+1} = y_n + h f(t_n, y_n).$$</p>
<p>Таблица Бутчера:
$$\begin{array}{c|c}
0 &amp; 0 \
\hline
&amp; 1
\end{array}$$</p>
<p>Локальная ошибка $O(h^2)$, глобальная $O(h)$ — поэтому <strong>порядок 1</strong>.</p>
<p><strong>По Wikipedia:</strong> «недостаток устойчивости и точности ограничивает популярность метода Эйлера — в основном он используется как простой вводный пример».</p>
<h2>Метод Хойна (Heun, явный, 2-стадийный, 2-го порядка)</h2>
<p>Идея: метод Эйлера даёт оценку $\tilde y_{n+1} = y_n + h f(t_n, y_n)$. Эта оценка использует наклон <strong>в начале</strong> отрезка. А что если ещё посчитать наклон <strong>в конце</strong> (по приближённой оценке $\tilde y_{n+1}$) и <strong>усреднить</strong>?</p>
<p>Формулы:
$$k_1 = f(t_n, y_n),$$
$$k_2 = f(t_n + h,; y_n + h k_1),$$
$$y_{n+1} = y_n + \tfrac{h}{2}(k_1 + k_2).$$</p>
<p>Таблица Бутчера:
$$\begin{array}{c|cc}
0 &amp; 0 &amp; 0 \
1 &amp; 1 &amp; 0 \
\hline
&amp; 1/2 &amp; 1/2
\end{array}$$</p>
<p><strong>Геометрическая интерпретация.</strong> Метод Хойна — это «правило трапеций» для интеграла $\int_{t_n}^{t_n+h} f,dt$, но с приближённой оценкой $y$ в правом конце. Поэтому он также называется «явным правилом трапеций» или «модифицированным методом Эйлера».</p>
<p><strong>Порядок: 2</strong>, локальная ошибка $O(h^3)$, глобальная $O(h^2)$.</p>
<h2>Метод средней точки (явный, 2-стадийный, 2-го порядка)</h2>
<p>Идея: оценить наклон <strong>в середине</strong> интервала. Сначала по Эйлеру с половинным шагом доходим до середины, потом считаем там $f$, и этим наклоном идём через весь шаг.</p>
<p>Формулы:
$$k_1 = f(t_n, y_n),$$
$$k_2 = f(t_n + \tfrac{h}{2},; y_n + \tfrac{h}{2} k_1),$$
$$y_{n+1} = y_n + h, k_2.$$</p>
<p>Таблица Бутчера:
$$\begin{array}{c|cc}
0 &amp; 0 &amp; 0 \
1/2 &amp; 1/2 &amp; 0 \
\hline
&amp; 0 &amp; 1
\end{array}$$</p>
<p><strong>Геометрическая интерпретация.</strong> Это «формула прямоугольников со средней точкой» для интеграла, опять же с приближённой оценкой $y$ в средней точке.</p>
<p><strong>Порядок: 2</strong>.</p>
<h2>Сравнение трёх методов на простом примере</h2>
<p>Возьмём $\dot y = y$, $y(0) = 1$. Точное решение $y(t) = e^t$. Шагнём на $h = 0.1$:</p>
<ul>
<li><strong>Эйлер:</strong> $y_1 = 1 + 0.1\cdot 1 = 1.1$. Точное значение $e^{0.1} \approx 1.10517$. Ошибка $\approx 5.2 \cdot 10^{-3}$.</li>
<li><strong>Хойн:</strong> $k_1 = 1$, $k_2 = f(0.1, 1.1) = 1.1$, $y_1 = 1 + 0.05\cdot(1 + 1.1) = 1.105$. Ошибка $\approx 1.7 \cdot 10^{-4}$.</li>
<li><strong>Средняя точка:</strong> $k_1 = 1$, $k_2 = f(0.05, 1.05) = 1.05$, $y_1 = 1 + 0.1\cdot 1.05 = 1.105$. Ошибка $\approx 1.7 \cdot 10^{-4}$.</li>
</ul>
<p>Видно: оба метода 2-го порядка дают ошибку <strong>в 30 раз меньше</strong>, чем Эйлер, при том же $h$, ценой одного дополнительного вычисления $f$.</p>
<h2>Что говорить на экзамене</h2>
<blockquote>
<p><strong>Общий вид $s$-стадийного метода РК:</strong>
$$k_i = f(t_n + c_i h,; y_n + h\textstyle\sum_j a_{ij} k_j), \qquad y_{n+1} = y_n + h\textstyle\sum_i b_i k_i.$$
Условия: $\sum_j a_{ij} = c_i$, $\sum_i b_i = 1$.</p>
<p><strong>Таблица Бутчера:</strong> компактная запись коэффициентов.</p>
<p><strong>Классификация:</strong> явные (нижнетреугольная $A$), DIRK, FIRK, вложенные.</p>
<p><strong>Эйлер</strong> ($s=1$, $p=1$): $y_{n+1} = y_n + hf(t_n, y_n)$.</p>
<p><strong>Хойн</strong> ($s=2$, $p=2$): два наклона — в начале и в конце шага, усредняем; «явное правило трапеций».</p>
<p><strong>Средняя точка</strong> ($s=2$, $p=2$): сначала Эйлер до середины, потом наклон оттуда — через весь шаг.</p>
</blockquote>

<h1>4. Обоснование одного из методов Рунге-Кутты 3-го или 4-го порядка (коэффициенты выдаёт преподаватель)</h1>
<blockquote>
<p><strong>Источники:</strong> Хайрер-Нёрсетт-Ваннер, гл. II.1 «Discussion of Methods of Order 4», стр. 135; гл. II.2 «Order Conditions for Runge-Kutta Methods», стр. 143–154 (условия порядка через ряды Тейлора); Wikipedia, "List of Runge–Kutta methods".</p>
</blockquote>
<h2>Зачем это нужно?</h2>
<p>Преподаватель на экзамене даст таблицу Бутчера какого-то метода и попросит <strong>доказать его порядок</strong>. Это значит: показать, что после одного шага метода численное приближение совпадает с точным решением <strong>с точностью до $h^{p+1}$</strong>. Метод с порядком $p$ — это метод, у которого локальная ошибка $\tau_n = y(t_n + h) - y_{n+1} = O(h^{p+1})$.</p>
<p>Ниже — общая методика обоснования. Конкретные коэффициенты подставляются в конце.</p>
<h2>Главная идея</h2>
<p>Сравним два разложения по степеням $h$:</p>
<ol>
<li>Разложение <strong>точного решения</strong> $y(t_n + h)$ по формуле Тейлора в точке $t_n$.</li>
<li>Разложение <strong>численного приближения</strong> $y_{n+1}$ по степеням $h$, полученное последовательной подстановкой $k_i$.</li>
</ol>
<p>Если коэффициенты при $h^0, h^1, h^2, \ldots, h^p$ в обоих разложениях совпадают, а при $h^{p+1}$ — нет, то метод <strong>порядка $p$</strong>.</p>
<h2>Шаги обоснования</h2>
<h3>Шаг 1. Разложение точного решения по Тейлору</h3>
<p>Для уравнения $\dot y = f(t, y)$ имеем:
$$y' = f, \qquad y'' = \frac{d}{dt}f(t, y(t)) = f_t + f_y\cdot\dot y = f_t + f_y, f.$$</p>
<p>Дальше по индукции: $y''' = f_{tt} + 2 f_{ty}, f + f_{yy}, f^2 + f_y, (f_t + f_y, f)$, и т.д. Все производные $y$ в точке $t_n$ выражаются через $f$ и её частные производные.</p>
<p><strong>Удобная нотация Хайрера</strong> (через «деревья»). Для каждой производной $y^{(k)}$ есть набор «элементарных дифференциалов» — выражений типа $f, ;f_y f, ;f_{yy}(f, f), ;f_y f_y f, ;\ldots$ Каждое такое выражение соответствует «корневому дереву» с $k$ узлами. Эта формализация позволяет систематически выписывать условия порядка для произвольных $p$ и $s$ (это и сделано в книге Хайрера, гл. II.2). Но для конкретных $p \le 4$ всё можно сделать «вручную».</p>
<p>Разложение точного решения:
$$y(t_n + h) = y_n + h, y' + \tfrac{h^2}{2}y'' + \tfrac{h^3}{6}y''' + \tfrac{h^4}{24}y^{(4)} + O(h^5),$$
все производные — в точке $t_n$, выражены через $f$ и её частные производные.</p>
<h3>Шаг 2. Разложение численного решения</h3>
<p>Для каждой стадии $k_i = f(t_n + c_i h, y_n + h\sum_j a_{ij} k_j)$ применяем разложение Тейлора <strong>двумерной функции</strong> $f$ в точке $(t_n, y_n)$:
$$k_i = f + h(c_i, f_t + (\textstyle\sum_j a_{ij} k_j), f_y) + \tfrac{h^2}{2}\big(c_i^2 f_{tt} + 2 c_i (\textstyle\sum_j a_{ij} k_j) f_{ty} + (\textstyle\sum_j a_{ij} k_j)^2 f_{yy}\big) + \ldots$$</p>
<p>Поскольку $k_j = f + O(h)$, первое приближение $\sum_j a_{ij} k_j \approx (\sum_j a_{ij}) f = c_i f$ (используя условие согласованности). Подставляя дальше и собирая степени $h$:
$$k_i = f + h c_i (f_t + f_y, f) + O(h^2).$$
Дальше — точно так же для следующих порядков.</p>
<p>Тогда:
$$y_{n+1} = y_n + h\textstyle\sum_i b_i k_i = y_n + h(\textstyle\sum_i b_i) f + h^2(\textstyle\sum_i b_i c_i)(f_t + f_y f) + h^3 (\ldots) + \ldots$$</p>
<h3>Шаг 3. Условия порядка (сравнение коэффициентов)</h3>
<p>Приравнивая коэффициенты при одинаковых $h^k$ в разложениях $y(t_n + h)$ и $y_{n+1}$, получаем <strong>условия порядка</strong>:</p>
<ul>
<li><strong>Порядок 1:</strong> $\sum_i b_i = 1$.</li>
<li><strong>Порядок 2:</strong> дополнительно $\sum_i b_i c_i = \tfrac{1}{2}$.</li>
<li><strong>Порядок 3:</strong> дополнительно $\sum_i b_i c_i^2 = \tfrac{1}{3}$ и $\sum_{i, j} b_i a_{ij} c_j = \tfrac{1}{6}$.</li>
<li><strong>Порядок 4:</strong> дополнительно (4 условия):
<ul>
<li>$\sum_i b_i c_i^3 = \tfrac{1}{4}$</li>
<li>$\sum_{i,j} b_i c_i a_{ij} c_j = \tfrac{1}{8}$</li>
<li>$\sum_{i,j} b_i a_{ij} c_j^2 = \tfrac{1}{12}$</li>
<li>$\sum_{i,j,k} b_i a_{ij} a_{jk} c_k = \tfrac{1}{24}$.</li>
</ul>
</li>
</ul>
<p>(У Хайрера это всё табулировано; см. таблицу 2.2 в книге, стр. 153.)</p>
<h3>Шаг 4. Проверить условия для данного метода</h3>
<p>Подставляем коэффициенты $a_{ij}, b_i, c_i$ из выданной таблицы Бутчера в условия порядка. Проверяем порядок 1, 2, 3, 4 — пока не найдётся условие, которое нарушается. Тогда заявленный порядок метода — последний из выполнившихся.</p>
<h2>Пример: классический RK4 (4-стадийный, 4-го порядка)</h2>
<p>Таблица Бутчера:
$$\begin{array}{c|cccc}
0 &amp; 0 &amp; 0 &amp; 0 &amp; 0 \
1/2 &amp; 1/2 &amp; 0 &amp; 0 &amp; 0 \
1/2 &amp; 0 &amp; 1/2 &amp; 0 &amp; 0 \
1 &amp; 0 &amp; 0 &amp; 1 &amp; 0 \
\hline
&amp; 1/6 &amp; 1/3 &amp; 1/3 &amp; 1/6
\end{array}$$</p>
<p>Формула:
$$y_{n+1} = y_n + \tfrac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4).$$</p>
<p><strong>Проверка условий порядка:</strong></p>
<ul>
<li>Порядок 1: $\sum b_i = 1/6 + 1/3 + 1/3 + 1/6 = 1$. ✓</li>
<li>Порядок 2: $\sum b_i c_i = (1/6)\cdot 0 + (1/3)\cdot(1/2) + (1/3)\cdot(1/2) + (1/6)\cdot 1 = 0 + 1/6 + 1/6 + 1/6 = 1/2$. ✓</li>
<li>Порядок 3, первое: $\sum b_i c_i^2 = 0 + (1/3)(1/4) + (1/3)(1/4) + (1/6)\cdot 1 = 1/12 + 1/12 + 1/6 = 1/3$. ✓</li>
<li>Порядок 3, второе: $\sum b_i a_{ij} c_j$. У RK4 ненулевые $a_{ij}$: $a_{21}=1/2, a_{32}=1/2, a_{43}=1$. Так что $\sum b_i a_{ij} c_j = b_2 a_{21} c_1 + b_3 a_{32} c_2 + b_4 a_{43} c_3 = (1/3)(1/2)(0) + (1/3)(1/2)(1/2) + (1/6)(1)(1/2) = 0 + 1/12 + 1/12 = 1/6$. ✓</li>
<li>Порядок 4 (все четыре условия) — аналогично, проверяются и все выполняются (читается в Хайрере, стр. 138, таблица 1.2).</li>
<li>Порядок 5: можно показать, что одно из условий 5-го порядка (их 9) уже <strong>не выполнено</strong>, поэтому RK4 — ровно 4-го порядка.</li>
</ul>
<p><strong>Заключение:</strong> метод порядка 4. Локальная ошибка $O(h^5)$, глобальная — $O(h^4)$.</p>
<h2>Пример: метод Хойна 3-го порядка</h2>
<p>Таблица Бутчера:
$$\begin{array}{c|ccc}
0 &amp; 0 &amp; 0 &amp; 0 \
1/3 &amp; 1/3 &amp; 0 &amp; 0 \
2/3 &amp; 0 &amp; 2/3 &amp; 0 \
\hline
&amp; 1/4 &amp; 0 &amp; 3/4
\end{array}$$</p>
<p><strong>Проверка:</strong></p>
<ul>
<li>Порядок 1: $\sum b_i = 1/4 + 0 + 3/4 = 1$. ✓</li>
<li>Порядок 2: $\sum b_i c_i = (1/4)\cdot 0 + 0 + (3/4)\cdot(2/3) = 1/2$. ✓</li>
<li>Порядок 3, первое: $\sum b_i c_i^2 = 0 + 0 + (3/4)\cdot(4/9) = 1/3$. ✓</li>
<li>Порядок 3, второе: $\sum b_i a_{ij} c_j = b_3 a_{32} c_2 = (3/4)\cdot(2/3)\cdot(1/3) = 1/6$. ✓</li>
</ul>
<p>(Условия 4-го порядка не выполняются — оставляем читателю проверить $\sum b_i c_i^3 = (3/4)(8/27) = 8/36 = 2/9 \ne 1/4$.)</p>
<p><strong>Заключение:</strong> метод порядка 3.</p>
<h2>Что говорить на экзамене</h2>
<blockquote>
<p><strong>Алгоритм обоснования порядка $p$ метода РК:</strong></p>
<ol>
<li>Раскладываем точное решение в ряд Тейлора до $h^{p+1}$.</li>
<li>Раскладываем $k_i$ и $y_{n+1}$ по $h$ в той же точке.</li>
<li>Приравниваем коэффициенты — получаем условия порядка.</li>
<li>Подставляем данные коэффициенты $a_{ij}, b_i, c_i$ в условия и проверяем.</li>
</ol>
<p><strong>Условия порядка</strong> (выучить!):</p>
<ul>
<li>Порядок 1: $\sum b_i = 1$.</li>
<li>Порядок 2: $\sum b_i c_i = 1/2$.</li>
<li>Порядок 3: $\sum b_i c_i^2 = 1/3$, $\sum b_i a_{ij} c_j = 1/6$.</li>
<li>Порядок 4: ещё 4 условия с правыми частями $1/4, 1/8, 1/12, 1/24$.</li>
</ul>
<p>Метод порядка $p$ означает локальную ошибку $O(h^{p+1})$ и глобальную $O(h^p)$.</p>
</blockquote>

<h1>5. Асимптотическая оценка локальной ошибки в РК через константы $M$ и $L$; метод Ралстона 2-го порядка с доказательством</h1>
<blockquote>
<p><strong>Источники:</strong> Хайрер-Нёрсетт-Ваннер, гл. II.3 «Error Estimation and Convergence for RK Methods», стр. 156–163 (rigorous error bounds, principal error term, global error); статья Ralston A. (1962) — недоступна, но содержание и ответ воспроизведены по Wikipedia, "List of Runge–Kutta methods".</p>
</blockquote>
<h2>Зачем это нужно?</h2>
<p>Знать порядок метода — хорошо, но недостаточно. Хочется знать <strong>константу</strong> в оценке ошибки: $|\tau_n| \le C\cdot h^{p+1}$. Где находится $C$? От чего зависит? Если $f$ хорошая (гладкая, ограниченная) — $C$ маленькое; если $f$ почти разрывная или быстро меняется — $C$ большое.</p>
<h2>Главная идея</h2>
<p>Все производные $y$ вдоль решения выражаются через $f$ и её частные производные. Если $f$:</p>
<ul>
<li><strong>ограничена</strong>: $|f| \le M$ на области $D$;</li>
<li><strong>липшицева</strong> по $y$ с константой $L$: $|f(t, y_1) - f(t, y_2)| \le L|y_1 - y_2|$.</li>
</ul>
<p>Тогда производные $y$ можно мажорировать через $M$ и $L$:</p>
<ul>
<li>$|y'| = |f| \le M$;</li>
<li>$|y''| = |f_t + f_y f|$. Если ещё $|f_t| \le M\cdot L$ (это можно получить как следствие липшицевости в подходящих условиях, грубо), а $|f_y| \le L$, то $|y''| \le ML + L M = 2ML$.</li>
<li>В общем случае по индукции: $|y^{(k)}| \le c_k M L^{k-1}$ для некоторых констант $c_k$.</li>
</ul>
<p>Тогда главный член локальной ошибки метода порядка $p$:
$$\tau_n = y(t_n + h) - y_{n+1} \sim h^{p+1} \cdot y^{(p+1)}(t_n) \cdot \text{(коэф. метода)},$$
поэтому
$$\boxed{;|\tau_n| \le C(\text{метод}) \cdot M\cdot L^p \cdot h^{p+1}.;}$$</p>
<p><strong>Содержательный смысл:</strong> ошибка пропорциональна скорости решения ($M$), степени «крутости» $f$ ($L^p$ — растёт при $L$ → большие, потому что любая малая ошибка быстро «раздувается»), и шагу в степени $p+1$.</p>
<h2>Метод Ралстона 2-го порядка</h2>
<p><strong>Постановка задачи Ралстона.</strong> Среди всех 2-стадийных явных методов 2-го порядка выбрать тот, у которого <strong>константа $C$ в главном члене локальной ошибки минимальна</strong>.</p>
<p><strong>Общий 2-стадийный явный метод 2-го порядка.</strong> Стадии:
$$k_1 = f(t_n, y_n), \qquad k_2 = f(t_n + \alpha h,; y_n + \alpha h k_1).$$
Шаг:
$$y_{n+1} = y_n + h(b_1 k_1 + b_2 k_2).$$</p>
<p>Условия 2-го порядка:
$$b_1 + b_2 = 1, \qquad b_2\cdot \alpha = 1/2.$$</p>
<p>Это даёт <strong>однопараметрическое семейство</strong>: $\alpha$ — свободный, $b_2 = 1/(2\alpha)$, $b_1 = 1 - 1/(2\alpha)$.</p>
<p>При $\alpha = 1$: $b_1 = b_2 = 1/2$ — это <strong>метод Хойна</strong>.
При $\alpha = 1/2$: $b_1 = 0, b_2 = 1$ — это <strong>метод средней точки</strong>.
При $\alpha = 2/3$: $b_1 = 1/4, b_2 = 3/4$ — это <strong>метод Ралстона</strong> (далее будет ясно, почему именно так).</p>
<h2>Доказательство (вывод $\alpha = 2/3$ как оптимального)</h2>
<p>Раскладываем $k_2$ по Тейлору:
$$k_2 = f + \alpha h(f_t + f f_y) + \tfrac{(\alpha h)^2}{2}(f_{tt} + 2 f f_{ty} + f^2 f_{yy}) + O(h^3).$$</p>
<p>Численное приближение:
$$y_{n+1} = y_n + h(b_1 + b_2) f + h^2 b_2 \alpha (f_t + f f_y) + h^3, b_2 \tfrac{\alpha^2}{2}(f_{tt} + 2 f f_{ty} + f^2 f_{yy}) + O(h^4).$$</p>
<p>Точное решение (расписав $y''$ и $y'''$):
$$y(t_n + h) = y_n + h f + \tfrac{h^2}{2}(f_t + f f_y) + \tfrac{h^3}{6}(f_{tt} + 2 f f_{ty} + f^2 f_{yy} + f_y f_t + f f_y^2) + O(h^4).$$</p>
<p>Разность (локальная ошибка):
$$\tau_n = y(t_n + h) - y_{n+1} = h^3!\left[!\left(\tfrac{1}{6} - \tfrac{b_2 \alpha^2}{2}\right)!(f_{tt} + 2 f f_{ty} + f^2 f_{yy}) + \tfrac{1}{6}(f_y f_t + f f_y^2)\right] + O(h^4).$$</p>
<p>Подставляя $b_2\alpha = 1/2$, имеем $b_2 \alpha^2 = \alpha/2$, поэтому первый коэффициент:
$$\tfrac{1}{6} - \tfrac{\alpha}{4}.$$</p>
<p>Главный член ошибки имеет вид:
$$\tau_n \approx h^3!\left[!\left(\tfrac{1}{6} - \tfrac{\alpha}{4}\right)(f_{tt} + 2 f f_{ty} + f^2 f_{yy}) + \tfrac{1}{6}(f_y f_t + f f_y^2)\right].$$</p>
<p><strong>Оценка модулем по константам $M, L$.</strong> При $|f| \le M$, $|f_y| \le L$ и допустимых дополнительных ограничениях на $f_t, f_{ty}, f_{tt}, f_{yy}$ имеем:
$$|f_{tt} + 2 f f_{ty} + f^2 f_{yy}| \le 4 M L^2, \qquad |f_y f_t + f f_y^2| \le 2 M L^2.$$
(Конкретные множители 4 и 2 зависят от того, какие именно мажоранты на $f_t$, $f_{ty}$ и т.д. использовать; порядок по $M, L$ — тот же.)</p>
<p>Получаем мажоранту:
$$|\tau_n| \le h^3 M L^2 !\left[ 4,\Big|\tfrac{1}{6} - \tfrac{\alpha}{4}\Big| + \tfrac{2}{6} \right].$$</p>
<p><strong>Минимизация по $\alpha$.</strong> Хотим минимизировать функцию $\Psi(\alpha) = |\tfrac{1}{6} - \tfrac{\alpha}{4}|$ — она достигает минимума (равного нулю) при $\alpha = \tfrac{2}{3}$.</p>
<p>При $\alpha = 2/3$ член $f_{tt} + 2 f f_{ty} + f^2 f_{yy}$ <strong>полностью обнуляется</strong> в локальной ошибке! Остаётся только член $\tfrac{h^3}{6}(f_y f_t + f f_y^2)$, и его коэффициент $\tfrac{1}{6}$ минимален среди возможных.</p>
<p>Подставляя $\alpha = 2/3$: $b_2 = 1/(2\cdot 2/3) = 3/4$, $b_1 = 1 - 3/4 = 1/4$.</p>
<p><strong>Метод Ралстона:</strong>
$$k_1 = f(t_n, y_n), \qquad k_2 = f(t_n + \tfrac{2h}{3},; y_n + \tfrac{2h}{3} k_1),$$
$$y_{n+1} = y_n + h!\left(\tfrac{1}{4} k_1 + \tfrac{3}{4} k_2\right).$$</p>
<p>Таблица Бутчера:
$$\begin{array}{c|cc}
0 &amp; 0 &amp; 0 \
2/3 &amp; 2/3 &amp; 0 \
\hline
&amp; 1/4 &amp; 3/4
\end{array}$$</p>
<p><strong>По Wikipedia:</strong> «Ralston's method is a second-order method with two stages and a minimum local error bound.»</p>
<h2>Что говорить на экзамене</h2>
<blockquote>
<p><strong>Локальная ошибка метода РК порядка $p$:</strong>
$$|\tau_n| \le C(\text{метод}) \cdot M\cdot L^p \cdot h^{p+1},$$
где $M = \sup |f|$, $L$ — константа Липшица $f$ по $y$.</p>
<p><strong>Метод Ралстона 2-го порядка:</strong> двухстадийный явный метод с $\alpha = 2/3$, минимизирующий главный член локальной ошибки.</p>
<p>Таблица: $c = (0, 2/3)$, $a_{21} = 2/3$, $b = (1/4, 3/4)$.</p>
<p><strong>Доказательство:</strong> для семейства 2-стадийных методов 2-го порядка ($b_2 \alpha = 1/2$) главный член ошибки имеет вид $h^3!\left[(1/6 - \alpha/4)(f_{tt} + 2 f f_{ty} + f^2 f_{yy}) + (1/6)(f_y f_t + f f_y^2)\right]$. Минимум $|1/6 - \alpha/4|$ — при $\alpha = 2/3$, тогда первая скобка зануляется. $b_2 = 3/4$, $b_1 = 1/4$ — Ралстон.</p>
</blockquote>

<h1>6. Общий вид вложенных методов РК; метод Хойна-Эйлера; подбор шага в одношаговых методах</h1>
<blockquote>
<p><strong>Источники:</strong> Хайрер-Нёрсетт-Ваннер, гл. II.4 «Practical Error Estimation and Step Size Selection», стр. 164–172 (Richardson extrapolation, embedded RK formulas, automatic step size control, starting step size); Wikipedia, "List of Runge–Kutta methods", разд. о вложенных методах.</p>
</blockquote>
<h2>Зачем это нужно?</h2>
<p>В реальных задачах <strong>заранее неизвестно</strong>, какой шаг $h$ выбрать. Если $h$ слишком мал — будем считать миллионы шагов вместо тысячи. Если $h$ слишком велик — точность плохая, может даже расходиться. Хочется метод, который <strong>сам подбирает $h$</strong> на каждом шаге, чтобы поддерживать ошибку в заданных рамках.</p>
<p>Чтобы подбирать $h$, надо уметь <strong>оценивать локальную ошибку</strong> на каждом шаге. Сделать это можно дёшево, если использовать <strong>вложенные методы</strong>.</p>
<h2>Главная идея</h2>
<p>Берём один шаг от $y_n$ к $y_{n+1}$ и выполняем его двумя методами <strong>разного порядка</strong> ($p$ и $\hat p = p \pm 1$), но используя одни и те же стадии $k_i$. Тогда:</p>
<ul>
<li>разница между двумя приближениями даёт оценку локальной ошибки;</li>
<li>стоимость одного шага — те же $s$ вычислений $f$ (стадии общие);</li>
<li>если оценка ошибки слишком велика — отвергаем шаг и пробуем меньший $h$.</li>
</ul>
<h2>Общий вид вложенного метода</h2>
<p>Таблица Бутчера расширяется ещё одной строкой:
$$\begin{array}{c|cccc}
c_1 &amp; a_{11} &amp; \cdots &amp; a_{1s} \
\vdots &amp; \vdots &amp; \ddots &amp; \vdots \
c_s &amp; a_{s1} &amp; \cdots &amp; a_{ss} \
\hline
&amp; b_1 &amp; \cdots &amp; b_s &amp; \quad(\text{порядок } p) \
&amp; \hat b_1 &amp; \cdots &amp; \hat b_s &amp; \quad(\text{порядок } \hat p)
\end{array}$$</p>
<p>Стадии общие:
$$k_i = f!\left(t_n + c_i h,; y_n + h\sum_j a_{ij} k_j\right).$$</p>
<p>Получаем два приближения:
$$y_{n+1} = y_n + h\sum_i b_i k_i \quad (\text{основное, порядка } p),$$
$$\hat y_{n+1} = y_n + h\sum_i \hat b_i k_i \quad (\text{контрольное, порядка } \hat p).$$</p>
<p><strong>Оценка локальной ошибки</strong> — разность:
$$\delta_n := y_{n+1} - \hat y_{n+1} = h\sum_i (b_i - \hat b_i), k_i.$$
Эта величина имеет порядок $O(h^{\min(p, \hat p)+1}) = O(h^{\hat p + 1})$ (если $\hat p &lt; p$) — то есть оценивает локальную ошибку <strong>метода низшего порядка</strong>.</p>
<h2>Метод Хойна-Эйлера (простейший вложенный)</h2>
<p>Из Wikipedia: «Простейший адаптивный метод РК — комбинация метода Хойна (порядка 2) с методом Эйлера (порядка 1)».</p>
<p>Таблица Бутчера:
$$\begin{array}{c|cc}
0 &amp; 0 &amp; 0 \
1 &amp; 1 &amp; 0 \
\hline
&amp; 1/2 &amp; 1/2 \quad(\text{Хойн, } p = 2) \
&amp; 1 &amp; 0 \quad;;(\text{Эйлер, } \hat p = 1)
\end{array}$$</p>
<p>Стадии:
$$k_1 = f(t_n, y_n), \qquad k_2 = f(t_n + h,; y_n + h k_1).$$</p>
<p>Оба приближения:
$$y_{n+1}^{\text{Heun}} = y_n + \tfrac{h}{2}(k_1 + k_2), \qquad y_{n+1}^{\text{Euler}} = y_n + h k_1.$$</p>
<p>Оценка ошибки:
$$\delta_n = y_{n+1}^{\text{Heun}} - y_{n+1}^{\text{Euler}} = \tfrac{h}{2}(k_2 - k_1).$$</p>
<p>Это оценивает ошибку <strong>Эйлера</strong> (порядка 1), которая $O(h^2)$ — то есть $\delta_n = O(h^2)$.</p>
<p>В практике в качестве «надёжного» приближения берут $y_{n+1}^{\text{Heun}}$ (более точное), а $\delta_n$ используют только для выбора шага.</p>
<p><strong>Более продвинутые вложенные методы:</strong> Фельберга RKF45 (порядки 4 и 5), Дорманда-Принса DOPRI45 (порядки 4 и 5, считается стандартом для нежёстких задач), Кэша-Карпа. Их таблицы — в Wikipedia.</p>
<h2>Подбор шага в одношаговых методах</h2>
<p><strong>Алгоритм адаптивного шага</strong> (по Хайреру, гл. II.4, стр. 167):</p>
<ol>
<li>
<p><strong>Заданный допуск</strong> $\text{tol}$. Обычно используют сочетание абсолютного и относительного допусков:
$$\text{sc}<em>i = \text{atol} + \text{rtol}\cdot\max(|y_n^i|, |y</em>{n+1}^i|), \qquad \text{err} = \sqrt{\tfrac{1}{n}\sum_i (\delta_n^i / \text{sc}_i)^2}.$$
То есть «масштабированная норма» ошибки относительно допустимого уровня.</p>
</li>
<li>
<p><strong>Если $\text{err} \le 1$ — шаг принимаем.</strong> Текущее приближение $y_{n+1}$ считаем хорошим.</p>
</li>
<li>
<p><strong>Оптимальный шаг.</strong> Поскольку $|\delta_n| \approx C h^{\hat p + 1}$, оптимальный шаг $h_{\text{opt}}$ — тот, при котором $\text{err} = 1$:
$$h_{\text{opt}} = h \cdot \left(\frac{1}{\text{err}}\right)^{1/(\hat p + 1)}.$$</p>
</li>
<li>
<p><strong>Коэффициент безопасности.</strong> Берём чуть меньший шаг для надёжности:
$$h_{\text{new}} = 0.9\cdot h_{\text{opt}}.$$
Также обычно вводят ограничения $h_{\text{new}} \in [0.2 h, 5 h]$, чтобы шаг не менялся слишком резко.</p>
</li>
<li>
<p><strong>Если $\text{err} &gt; 1$</strong> — шаг отвергаем, возвращаемся к $y_n$ и пробуем шагнуть с $h_{\text{new}}$.</p>
</li>
</ol>
<p><strong>Алгоритм выбора начального шага</strong> (Хайрер, стр. 169) — отдельный технический трюк, основанный на оценке $|y'(t_0)|$ и $|y''(t_0)|$.</p>
<h2>Что говорить на экзамене</h2>
<blockquote>
<p><strong>Вложенный метод РК:</strong> в таблице Бутчера два набора весов $\mathbf{b}$ (порядок $p$) и $\hat{\mathbf{b}}$ (порядок $\hat p = p\pm 1$), общие стадии $k_i$.</p>
<p>Локальная ошибка оценивается как $\delta_n = h\sum_i (b_i - \hat b_i) k_i \sim h^{\hat p + 1}$.</p>
<p><strong>Хойн-Эйлер:</strong> $\delta_n = (h/2)(k_2 - k_1)$, где $k_1 = f(t_n, y_n)$, $k_2 = f(t_n + h, y_n + h k_1)$.</p>
<p><strong>Подбор шага:</strong></p>
<ol>
<li>Сделать шаг с текущим $h$, оценить $\text{err}$.</li>
<li>Если $\text{err} \le 1$ — принять; иначе отвергнуть.</li>
<li>$h_{\text{new}} = 0.9 \cdot h \cdot \text{err}^{-1/(\hat p + 1)}$.</li>
</ol>
</blockquote>

<h1>7. Обусловленность вычислительной задачи (прямая и относительная); расчёт числа обусловленности</h1>
<h2>Зачем это нужно?</h2>
<p>В вычислениях всегда есть <strong>погрешности входных данных</strong>: округление, ошибки измерений, ошибки представления в компьютере. Хотим понять: насколько эти ошибки <strong>исказят результат</strong>.</p>
<p>Если задача хорошо обусловлена — небольшие ошибки в входе дают небольшие ошибки в выходе. Если плохо обусловлена — даже идеально точный алгоритм даст плохой ответ из-за неточностей входа.</p>
<p>Важно: <strong>обусловленность — свойство задачи</strong>, не алгоритма. Можно изменить формулу и получить ту же задачу, но более устойчивой к ошибкам.</p>
<h2>Главная идея</h2>
<p>Имеем функцию $y = F(x)$ — задача: «по входу $x$ найти выход $y$». Пусть $x$ возмущено на $\delta x$, тогда $y$ возмутится на:
$$\delta y \approx F'(x)\cdot \delta x \quad \text{(в одномерном случае)}.$$</p>
<p>В векторном случае $F'$ — матрица Якоби, $\delta y \approx J\cdot \delta x$.</p>
<h2>Прямое (абсолютное) число обусловленности</h2>
<p>$$\boxed{;\kappa_{\text{abs}} = \sup_{\delta x \ne 0} \frac{|\delta y|}{|\delta x|} ;=; |F'(x)|.;}$$</p>
<p>Это — <strong>коэффициент усиления</strong> абсолютной ошибки.</p>
<h2>Относительное число обусловленности</h2>
<p>В приложениях обычно интересна <strong>относительная</strong> ошибка. Определение:
$$\boxed{;\kappa_{\text{rel}} = \sup_{\delta x \ne 0} \frac{|\delta y|/|y|}{|\delta x|/|x|} ;=; \frac{|x|\cdot |F'(x)|}{|F(x)|}.;}$$</p>
<p><strong>Содержательно:</strong> если относительная ошибка входа равна $\varepsilon$, то относительная ошибка выхода $\le \kappa_{\text{rel}}\cdot \varepsilon$.</p>
<p><strong>Если $\kappa_{\text{rel}} = 1$</strong> — задача идеальная: ошибки не усиливаются.
<strong>Если $\kappa_{\text{rel}} \approx 10^k$</strong> — теряется $k$ десятичных цифр при вычислении.
<strong>Если $\kappa_{\text{rel}} \to \infty$</strong> — задача катастрофически плохо обусловлена.</p>
<h2>Многомерный случай</h2>
<p>Для $y = F(x_1, \ldots, x_n)$:
$$\delta y \approx \sum_i \frac{\partial F}{\partial x_i}, \delta x_i.$$
Если относительные ошибки входа равны $\varepsilon$ ($|\delta x_i|/|x_i| \le \varepsilon$), то:
$$\frac{|\delta y|}{|y|} \le \varepsilon\cdot\sum_i \left|\frac{x_i}{F},\frac{\partial F}{\partial x_i}\right|.$$
Сумма в скобке — <strong>число обусловленности</strong> многомерной формулы.</p>
<h2>Пример: $f(x, y) = x^2 - y^2$</h2>
<p>(Пример из материалов преподавателя; ссылка на math.stackexchange.)</p>
<p><strong>Частные производные:</strong> $\partial f/\partial x = 2x$, $\partial f/\partial y = -2y$.</p>
<p><strong>Возмущение:</strong> $\delta f \approx 2x,\delta x - 2y,\delta y$.</p>
<p><strong>Относительная ошибка</strong> при $|\delta x|/|x| = |\delta y|/|y| = \varepsilon$:
$$\frac{|\delta f|}{|f|} \approx \frac{2|x||\delta x| + 2|y||\delta y|}{|x^2 - y^2|} = \varepsilon\cdot \frac{2x^2 + 2y^2}{|x^2 - y^2|}.$$</p>
<p><strong>Относительное число обусловленности:</strong>
$$\boxed{;\kappa_{\text{rel}} = \frac{2(x^2 + y^2)}{|x^2 - y^2|}.;}$$</p>
<p><strong>Анализ.</strong></p>
<ul>
<li>Если $|x|, |y|$ — порядка единицы и далеко друг от друга — $\kappa_{\text{rel}}$ умеренное.</li>
<li>Если $x \approx y$ — знаменатель $\to 0$, $\kappa_{\text{rel}} \to \infty$. <strong>Катастрофа.</strong> Это известное явление <strong>«катастрофического сокращения»</strong> при вычитании близких чисел.</li>
</ul>
<p><strong>Численный пример.</strong> $x = 1.0001$, $y = 1.0000$. Тогда:</p>
<ul>
<li>$x^2 \approx 1.00020001$, $y^2 = 1.00000000$. Разность $\approx 2\cdot 10^{-4}$.</li>
<li>$\kappa_{\text{rel}} = 2(1.00020001 + 1)/2\cdot 10^{-4} \approx 2\cdot 10^4$.</li>
<li>При относительной ошибке входа $\varepsilon = 10^{-7}$ (одинарная точность float) ошибка результата $\sim 2\cdot 10^4\cdot 10^{-7} = 2\cdot 10^{-3}$ — потеряли 4 цифры из 7.</li>
</ul>
<p><strong>Способ улучшить.</strong> Алгебраическое тождество: $x^2 - y^2 = (x - y)(x + y)$. Тогда катастрофическое сокращение происходит только в множителе $(x - y)$, что неизбежно в самой задаче, но другой множитель и сама структура формулы часто оказываются устойчивее.</p>
<h2>Что говорить на экзамене</h2>
<blockquote>
<p><strong>Обусловленность</strong> — мера чувствительности задачи к возмущениям входа. Свойство <strong>задачи</strong>, не алгоритма.</p>
<p><strong>Прямое число обусловленности:</strong> $\kappa_{\text{abs}} = |F'(x)|$.</p>
<p><strong>Относительное число обусловленности:</strong> $\kappa_{\text{rel}} = \dfrac{|x|\cdot |F'(x)|}{|F(x)|}$ — коэффициент усиления <strong>относительной</strong> ошибки.</p>
<p><strong>Многомерный случай:</strong> $\kappa_{\text{rel}} = \sum_i\left|\dfrac{x_i}{F}\dfrac{\partial F}{\partial x_i}\right|$.</p>
<p><strong>Пример $f(x, y) = x^2 - y^2$:</strong> $\kappa_{\text{rel}} = \dfrac{2(x^2 + y^2)}{|x^2 - y^2|}$. При $x \approx y$ катастрофически плохо обусловлена.</p>
<p><strong>Алгоритм расчёта числа обусловленности любой формулы:</strong></p>
<ol>
<li>Найти частные производные $\partial F/\partial x_i$.</li>
<li>Подставить в формулу $\kappa_{\text{rel}} = \sum |x_i F_{x_i}/F|$.</li>
<li>Упростить.</li>
</ol>
</blockquote>

<h1>8. Устойчивость методов численного интегрирования (на примере распада); неявные методы Эйлера, средней точки, трапеций</h1>
<blockquote>
<p><strong>Источники:</strong> Wikipedia, "Stiff equation" (тестовое уравнение, A-устойчивость, регионы устойчивости явного и неявного Эйлера, метода трапеций); Wikipedia, "Trapezoidal rule (differential equations)" (вывод метода трапеций, порядок 2, A-устойчивость).</p>
</blockquote>
<h2>Зачем это нужно?</h2>
<p>Бывают ОДУ, у которых решение быстро затухает, например:
$$\dot y = -1000 y, \quad y(0) = 1 ;\Rightarrow; y(t) = e^{-1000 t}.$$
Это уравнение <strong>жёсткое</strong>: оно описывает быстрый процесс, и любая ошибка в численном решении должна тоже быстро затухать. Иначе мы получим осциллирующий взрыв.</p>
<p>Окажется, что <strong>явные методы (Эйлер, Хойн, ...)</strong> для жёстких задач требуют <strong>очень малого шага</strong> $h$, иначе расходятся. <strong>Неявные методы</strong> свободны от этого ограничения — они <strong>A-устойчивы</strong>.</p>
<h2>Тестовое уравнение</h2>
<p>Стандартный «пробный камень» — линейное уравнение:
$$\dot y = \lambda y, \qquad y(0) = 1, \qquad \text{Re},\lambda &lt; 0.$$
Точное решение: $y(t) = e^{\lambda t} \to 0$ при $t \to \infty$.</p>
<p>Применим к нему численный метод. Получится формула вида $y_{n+1} = R(z)\cdot y_n$, где $z = h\lambda$, а $R(z)$ — <strong>функция устойчивости</strong> метода.</p>
<p><strong>A-устойчивость:</strong> метод A-устойчив, если для всех $z$ с $\text{Re},z &lt; 0$ выполняется $|R(z)| &lt; 1$. То есть численное решение тоже стремится к нулю при любом $h &gt; 0$, как и точное.</p>
<p>Множество ${z : |R(z)| \le 1}$ — <strong>область абсолютной устойчивости</strong> метода.</p>
<h2>Явный метод Эйлера</h2>
<p>$$y_{n+1} = y_n + h f(t_n, y_n) = y_n + h\lambda y_n = (1 + h\lambda) y_n.$$</p>
<p>Функция устойчивости: $R(z) = 1 + z$.</p>
<p><strong>Область устойчивости:</strong> $|1 + z| \le 1$ — это <strong>круг радиуса 1 с центром в $-1$</strong>.</p>
<p><strong>Вывод:</strong> для $\lambda$ вещественного отрицательного нужно $|1 + h\lambda| \le 1$, то есть $0 \le h \le 2/|\lambda|$. При $|\lambda| = 1000$ это $h \le 0.002$ — то есть <strong>2000 шагов на каждую единицу времени</strong>! При больших $|\lambda|$ метод практически непригоден.</p>
<p><strong>Не A-устойчив.</strong></p>
<h2>Неявный (обратный) метод Эйлера</h2>
<p><strong>Идея.</strong> В обычном Эйлере наклон берётся в начале шага: $\dot y \approx f(t_n, y_n)$. В неявном — в <strong>конце</strong>: $\dot y \approx f(t_{n+1}, y_{n+1})$.</p>
<p>Формула:
$$\boxed{; y_{n+1} = y_n + h f(t_{n+1}, y_{n+1}). ;}$$</p>
<p>Это <strong>неявная</strong> формула: $y_{n+1}$ стоит и слева, и в правой части как аргумент $f$. Чтобы её посчитать — надо решать <strong>уравнение</strong> относительно $y_{n+1}$ (например, методом Ньютона).</p>
<p><strong>Применение к тестовому уравнению:</strong>
$$y_{n+1} = y_n + h\lambda y_{n+1} ;\Rightarrow; y_{n+1} = \frac{1}{1 - h\lambda} y_n.$$</p>
<p>Функция устойчивости: $R(z) = \dfrac{1}{1 - z}$.</p>
<p><strong>Область устойчивости:</strong> $|1 - z| \ge 1$ — это <strong>внешность круга радиуса 1 с центром в $+1$</strong>. Включает всю левую полуплоскость $\text{Re}, z &lt; 0$ — значит, метод <strong>A-устойчив</strong>.</p>
<p>Более того, $|R(z)| \to 0$ при $\text{Re},z \to -\infty$ — метод <strong>L-устойчив</strong> (быстрые компоненты сильно гасятся, что важно для жёстких задач).</p>
<p><strong>Порядок: 1</strong>.</p>
<h2>Неявный метод средней точки</h2>
<p><strong>Идея.</strong> Применить формулу прямоугольников со средней точкой к интегралу
$$y(t_{n+1}) - y(t_n) = \int_{t_n}^{t_{n+1}} f(t, y(t)),dt \approx h\cdot f\big(t_n + \tfrac{h}{2},; y(t_n + \tfrac{h}{2})\big).$$
Заменим $y(t_n + h/2)$ на среднее арифметическое $(y_n + y_{n+1})/2$:</p>
<p>$$\boxed{; y_{n+1} = y_n + h f!\left(t_n + \tfrac{h}{2},;; \tfrac{y_n + y_{n+1}}{2}\right). ;}$$</p>
<p><strong>Тестовое уравнение:</strong>
$$y_{n+1} = y_n + h\lambda \tfrac{y_n + y_{n+1}}{2} ;\Rightarrow; y_{n+1}!\left(1 - \tfrac{h\lambda}{2}\right) = y_n!\left(1 + \tfrac{h\lambda}{2}\right) ;\Rightarrow; y_{n+1} = \frac{1 + h\lambda/2}{1 - h\lambda/2}, y_n.$$</p>
<p>Функция устойчивости: $R(z) = \dfrac{1 + z/2}{1 - z/2}$ — <strong>аппроксимация Паде</strong> $(1,1)$ для $e^z$.</p>
<p><strong>Анализ.</strong> $|R(z)|^2 = \dfrac{(1 + x/2)^2 + (y/2)^2}{(1 - x/2)^2 + (y/2)^2}$, где $z = x + iy$. Это $\le 1$ ровно при $x \le 0$. То есть <strong>область устойчивости — точно левая полуплоскость</strong>: метод <strong>A-устойчив</strong>.</p>
<p>Но <strong>не L-устойчив</strong>: $|R(z)| \to 1$ при $\text{Re},z \to -\infty$ — быстрые компоненты гасятся слабо.</p>
<p><strong>Порядок: 2</strong>.</p>
<h2>Неявный метод трапеций</h2>
<p><strong>Идея.</strong> Применить формулу трапеций к интегралу:
$$y(t_{n+1}) - y(t_n) = \int_{t_n}^{t_{n+1}} f(t, y(t)),dt \approx \tfrac{h}{2}\big[f(t_n, y(t_n)) + f(t_{n+1}, y(t_{n+1}))\big].$$</p>
<p>Получаем:
$$\boxed{; y_{n+1} = y_n + \tfrac{h}{2}\big[f(t_n, y_n) + f(t_{n+1}, y_{n+1})\big]. ;}$$</p>
<p>(Это также называют <strong>методом Кранка-Николсона</strong> в контексте УрЧП.)</p>
<p><strong>Тестовое уравнение:</strong>
$$y_{n+1} = y_n + \tfrac{h\lambda}{2}(y_n + y_{n+1}) ;\Rightarrow; y_{n+1} = \frac{1 + h\lambda/2}{1 - h\lambda/2} y_n.$$</p>
<p><strong>Та же функция устойчивости</strong>, что и у метода средней точки! $R(z) = (1 + z/2)/(1 - z/2)$.</p>
<p><strong>A-устойчив, не L-устойчив, порядок 2.</strong></p>
<p>По Wikipedia («Trapezoidal rule (differential equations)»): «область абсолютной устойчивости метода трапеций — в точности левая полуплоскость». Также по второму барьеру Дальквиста — это <strong>наиболее точный</strong> A-устойчивый линейный многошаговый метод (среди методов произвольного числа шагов).</p>
<h2>Сравнение и выводы</h2>

Метод | Тип | Порядок | Область устойчивости | A-уст. | L-уст.
-- | -- | -- | -- | -- | --
Эйлер явный | явный | 1 | круг $ | z+1 | \le 1$
Эйлер неявный | неявный | 1 | внешность круга $ | z-1 | \ge 1$ (включает левую плоскость)
Средняя точка явная | явный | 2 | ограниченная область | нет | нет
Средняя точка неявная | неявный | 2 | левая полуплоскость | да | нет
Трапеции | неявный | 2 | левая полуплоскость | да | нет
Хойн | явный | 2 | ограниченная область | нет | нет


<p><strong>Неявный Эйлер:</strong> $y_{n+1} = y_n + h f(t_{n+1}, y_{n+1})$ — порядок 1, L-устойчив.
<strong>Метод средней точки (неявный):</strong> $y_{n+1} = y_n + h f(t_n + h/2, (y_n + y_{n+1})/2)$ — порядок 2.
<strong>Метод трапеций:</strong> $y_{n+1} = y_n + (h/2)[f(t_n, y_n) + f(t_{n+1}, y_{n+1})]$ — порядок 2, A-устойчив (по второму барьеру Дальквиста — наиболее точный среди A-устойчивых линейных многошаговых).</p>
</blockquote>

<h1>9. Обобщения методов РК на произвольное число переменных и с автономных систем на неавтономные</h1>
<blockquote>
<p><strong>Источники:</strong> Хайрер-Нёрсетт-Ваннер, гл. II.1 «General Formulation of Runge-Kutta Methods», стр. 134; Wikipedia, "List of Runge–Kutta methods".</p>
</blockquote>
<h2>Зачем это нужно?</h2>
<p>В вопросе 3 я писал общую формулу РК для <strong>скалярного</strong> уравнения $\dot y = f(t, y)$. Реальные задачи — векторные (например, задача $N$ тел — система $6N$ уравнений). И они часто <strong>неавтономные</strong> — $f$ зависит явно от $t$. Покажем, что обобщение тривиально, но за этим стоит важное <strong>условие согласованности</strong> $\sum_j a_{ij} = c_i$.</p>
<h2>Обобщение на векторные системы</h2>
<p>Пусть $\mathbf{y}(t) \in \mathbb{R}^n$, $\mathbf{f}: \mathbb{R}\times\mathbb{R}^n \to \mathbb{R}^n$. Уравнение: $\dot{\mathbf{y}} = \mathbf{f}(t, \mathbf{y})$.</p>
<p>Формулы метода РК:
$$\mathbf{k}_i = \mathbf{f}!\left(t_n + c_i h,; \mathbf{y}<em>n + h\sum_j a</em>{ij}, \mathbf{k}<em>j\right) \in \mathbb{R}^n,$$
$$\mathbf{y}</em>{n+1} = \mathbf{y}_n + h\sum_i b_i, \mathbf{k}_i.$$</p>
<p><strong>Что изменилось:</strong> $\mathbf{k}<em>i$, $\mathbf{y}<em>n$, $\mathbf{y}</em>{n+1}$ — теперь <strong>векторы</strong> $\mathbb{R}^n$. Коэффициенты $a</em>{ij}, b_i, c_i$ — <strong>те же скаляры</strong> для всех компонент.</p>
<p><strong>Условия порядка</strong> (вопрос 4) тоже не меняются — они обеспечивают совпадение разложений Тейлора в <strong>каждой компоненте</strong> независимо.</p>
<p><strong>Стоимость шага.</strong> $s$ вычислений $\mathbf{f}$, каждое — это $n$ скалярных функций. Итого $s\cdot n$ скалярных вычислений.</p>
<h2>Автономизация: переход от неавтономной к автономной</h2>
<p><strong>Автономная система:</strong> $\dot{\mathbf{y}} = \mathbf{f}(\mathbf{y})$, $\mathbf{f}$ не зависит от $t$.
<strong>Неавтономная:</strong> $\dot{\mathbf{y}} = \mathbf{f}(t, \mathbf{y})$, $\mathbf{f}$ зависит от $t$ явно.</p>
<p><strong>Трюк автономизации.</strong> Введём дополнительную фиктивную компоненту $y_{n+1}(t) := t$ с уравнением $\dot y_{n+1} = 1$ и начальным $y_{n+1}(t_0) = t_0$. Тогда расширенный вектор $\tilde{\mathbf{y}} = (\mathbf{y}, y_{n+1}) \in \mathbb{R}^{n+1}$ удовлетворяет автономной системе:
$$\dot{\tilde{\mathbf{y}}} = \tilde{\mathbf{f}}(\tilde{\mathbf{y}}), \qquad \tilde{\mathbf{f}}(\tilde{\mathbf{y}}) := (\mathbf{f}(y_{n+1}, \mathbf{y}),; 1).$$</p>
<p>То есть любую неавтономную систему можно рассматривать как автономную <strong>в большем пространстве</strong>.</p>
<h2>Согласованность РК с автономизацией</h2>
<p><strong>Вопрос:</strong> если применить метод РК к неавтономной системе $\dot{\mathbf{y}} = \mathbf{f}(t, \mathbf{y})$, и отдельно к её автономизации $\dot{\tilde{\mathbf{y}}} = \tilde{\mathbf{f}}(\tilde{\mathbf{y}})$ — получится ли одно и то же приближение?</p>
<p><strong>Применим РК к автономной расширенной системе.</strong> Стадии:
$$\tilde{\mathbf{k}}_i = \tilde{\mathbf{f}}!\left(\tilde{\mathbf{y}}<em>n + h\sum_j a</em>{ij} \tilde{\mathbf{k}}_j\right).$$</p>
<p>Расписывая по компонентам: для скалярной части $y_{n+1}$ имеем $\tilde k_i^{n+1} = 1$ для всех $i$. Тогда $h\sum_j a_{ij}\cdot 1 = h\sum_j a_{ij}$. То есть аргумент $\tilde{\mathbf{f}}$ в $i$-й стадии — это $(t_n + h\sum_j a_{ij}, \mathbf{y}<em>n + h\sum_j a</em>{ij}\mathbf{k}_j)$.</p>
<p><strong>Сравним с прямым применением РК к неавтономной:</strong>
$$\mathbf{k}_i = \mathbf{f}!\left(t_n + c_i h,; \mathbf{y}<em>n + h\sum_j a</em>{ij} \mathbf{k}_j\right).$$</p>
<p>Эти две формулы <strong>совпадают тогда и только тогда</strong>, когда:
$$\boxed{;c_i = \sum_j a_{ij} \quad \text{для всех } i.;}$$</p>
<p><strong>Это и есть условие согласованности из вопроса 3.</strong> Оно гарантирует, что метод РК <strong>инвариантен относительно автономизации</strong> — то есть применять его к неавтономной системе или к её автономному расширению даёт <strong>одинаковое приближение</strong>.</p>
<p><strong>Вывод:</strong> условие согласованности — не просто формальность из определения, а содержательное требование <strong>корректности</strong>.</p>
<h2>Что говорить на экзамене</h2>
<blockquote>
<p><strong>Векторный случай:</strong> все формулы метода РК переносятся на $\mathbf{y} \in \mathbb{R}^n$ покомпонентно. Стадии $\mathbf{k}<em>i$ — векторы; коэффициенты $a</em>{ij}, b_i, c_i$ — те же скаляры.</p>
<p><strong>Автономизация:</strong> неавтономная система $\dot{\mathbf{y}} = \mathbf{f}(t, \mathbf{y})$ сводится к автономной добавлением компоненты $\dot t = 1$.</p>
<p><strong>Согласованность с автономизацией:</strong> РК-метод даёт одно и то же приближение на исходной неавтономной задаче и на её автономизации <strong>тогда и только тогда</strong>, когда $\sum_j a_{ij} = c_i$. Это и есть стандартное условие согласованности из таблицы Бутчера.</p>
</blockquote>

<h1>10. Интерполяционные многочлены Лагранжа и Ньютона; сходства и различия; формула ошибки интерполяции (с доказательством)</h1>
<blockquote>
<p><strong>Источник:</strong> НОУ ИНТУИТ, курс «Введение в вычислительную математику», лекция 7 «Интерполяция функций», стр./разд. 6.3 и 6.4 + теорема об остаточном члене.</p>
</blockquote>
<h2>Зачем это нужно?</h2>
<p>Часто известны значения функции $f$ только в нескольких точках $(t_0, f_0), (t_1, f_1), \ldots, (t_n, f_n)$, а нужна её аппроксимация на всём отрезке. Самый простой способ — провести через эти точки <strong>многочлен</strong>. Это <strong>интерполяция</strong>.</p>
<p>Интерполяционные многочлены используются всюду: для приближённого вычисления $f$ в промежуточных точках, для построения квадратурных формул (вопрос 19), для получения формул численного дифференцирования (вопрос 18), для многошаговых методов решения ОДУ (вопрос 12).</p>
<h2>Постановка задачи</h2>
<p>Дана сетка $t_0 &lt; t_1 &lt; \ldots &lt; t_n$ и значения $f_k = f(t_k)$. <strong>Найти</strong> многочлен $P_n(t)$ степени $\le n$, такой что $P_n(t_k) = f_k$ для всех $k = 0, 1, \ldots, n$.</p>
<p><strong>Существование и единственность.</strong> Многочлен степени $\le n$ имеет $n+1$ коэффициент. У нас $n+1$ условие. Получается линейная система — её матрица называется <strong>матрицей Вандермонда</strong>, и её определитель отличен от нуля при различных узлах. Поэтому интерполяционный многочлен существует и единствен.</p>
<p>Дальше — две <strong>формы записи</strong> одного и того же многочлена.</p>
<h2>Форма Лагранжа</h2>
<p><strong>Идея.</strong> Построить базисные многочлены $l_k(t)$ степени $n$ со свойством:
$$l_k(t_j) = \delta_{kj} = \begin{cases} 1, &amp; j = k \ 0, &amp; j \ne k \end{cases}$$
Тогда сумма $L_n(t) = \sum_k f_k, l_k(t)$ автоматически даст $L_n(t_j) = f_j$.</p>
<p><strong>Явная формула $l_k$.</strong> Многочлен $\prod_{j \ne k}(t - t_j)$ обращается в ноль во всех узлах, кроме $t_k$. В $t_k$ он равен $\prod_{j \ne k}(t_k - t_j)$. Нормируем:
$$\boxed{;l_k(t) = \prod_{j=0,, j\ne k}^{n} \frac{t - t_j}{t_k - t_j}.;}$$</p>
<p><strong>Многочлен Лагранжа:</strong>
$$\boxed{;L_n(t) = \sum_{k=0}^{n} f_k, l_k(t).;}$$</p>
<h2>Форма Ньютона</h2>
<p><strong>Идея.</strong> Записать многочлен в «возрастающем» базисе:
$$N_n(t) = c_0 + c_1(t - t_0) + c_2(t - t_0)(t - t_1) + \ldots + c_n(t-t_0)(t-t_1)\cdots(t-t_{n-1}).$$</p>
<p>Коэффициенты $c_k$ называются <strong>разделёнными разностями</strong> и определяются рекуррентно (см. вопрос 11). Обозначаются:
$$c_k = f[t_0, t_1, \ldots, t_k].$$</p>
<p>Многочлен Ньютона:
$$\boxed{;N_n(t) = \sum_{k=0}^{n} f[t_0, \ldots, t_k] \prod_{j=0}^{k-1}(t - t_j).;}$$</p>
<h2>Сходства и различия</h2>
<p><strong>Сходство:</strong> $L_n \equiv N_n$ — это <strong>один и тот же многочлен</strong> (в силу единственности интерполяционного полинома). Это две <strong>разные формы записи</strong>.</p>
<p><strong>Различия:</strong></p>
<ol>
<li>
<p><strong>Лагранж:</strong> коэффициенты при $f_k$ выписываются явно через узлы. Удобно для теоретических оценок (например, в выводе формулы ошибки).</p>
</li>
<li>
<p><strong>Ньютон:</strong> коэффициенты $c_k$ нужно сначала посчитать через таблицу разделённых разностей. Зато:</p>
<ul>
<li><strong>Добавление узла:</strong> чтобы перейти от $N_n$ к $N_{n+1}$, достаточно посчитать одну новую разделённую разность $f[t_0, \ldots, t_{n+1}]$ и добавить одно слагаемое. У Лагранжа все базисные функции пересчитываются с нуля.</li>
<li><strong>Оценка ошибки на следующей точке:</strong> добавочное слагаемое $f[t_0, \ldots, t_{n+1}]\prod_{j=0}^n(t - t_j)$ — это поправка к интерполяции, оно непосредственно показывает, насколько добавление новой точки изменит значение многочлена.</li>
<li><strong>Численная устойчивость</strong> обычно лучше у Ньютона.</li>
</ul>
</li>
</ol>
<h2>Формула ошибки интерполяции</h2>
<p><strong>Теорема.</strong> Пусть $f \in C^{n+1}[a, b]$, и узлы $t_0, \ldots, t_n \in [a, b]$. Тогда для любого $t \in [a, b]$ существует $\xi \in [a, b]$ (зависящее от $t$), такое что
$$\boxed{;f(t) - P_n(t) = \frac{f^{(n+1)}(\xi)}{(n+1)!}, \omega_{n+1}(t),;}$$
где
$$\omega_{n+1}(t) = (t - t_0)(t - t_1)\cdots(t - t_n) = \prod_{k=0}^{n}(t - t_k).$$</p>
<p><strong>Содержательно.</strong> Ошибка имеет два множителя:</p>
<ul>
<li>$f^{(n+1)}/((n+1)!)$ — характеризует «гладкость» $f$ (сколько у неё производных и насколько они большие);</li>
<li>$\omega_{n+1}(t)$ — зависит от расположения узлов и от точки $t$, в которой считаем; в узлах $\omega_{n+1}(t_k) = 0$, между узлами — отлична от нуля.</li>
</ul>
<h2>Доказательство формулы ошибки</h2>
<p><strong>Случай 1.</strong> Если $t = t_k$ для какого-то $k$, то обе стороны равенства нулевые: $f(t_k) - P_n(t_k) = 0$ по интерполяции, $\omega_{n+1}(t_k) = 0$ по построению. Утверждение тривиально.</p>
<p><strong>Случай 2.</strong> Пусть $t$ — фиксированная точка, не совпадающая ни с одним $t_k$.</p>
<p><strong>Шаг 1. Вспомогательная функция.</strong> Введём константу
$$K = \frac{f(t) - P_n(t)}{\omega_{n+1}(t)},$$
и функцию переменной $s$:
$$\varphi(s) = f(s) - P_n(s) - K\cdot \omega_{n+1}(s).$$</p>
<p><strong>Шаг 2. У $\varphi$ есть $n+2$ нуля.</strong></p>
<ul>
<li>$\varphi(t_k) = f(t_k) - P_n(t_k) - K\cdot \omega_{n+1}(t_k) = 0 - 0 = 0$ для всех $k = 0, \ldots, n$. Это $n+1$ нулей.</li>
<li>$\varphi(t) = f(t) - P_n(t) - K\cdot\omega_{n+1}(t) = f(t) - P_n(t) - (f(t) - P_n(t)) = 0$. Ещё один нуль.</li>
</ul>
<p>Итого: $n+2$ различных нулей.</p>
<p><strong>Шаг 3. Применяем теорему Ролля.</strong> Между каждыми двумя нулями функции есть нуль её производной. Значит:</p>
<ul>
<li>У $\varphi$ — $n+2$ нулей.</li>
<li>У $\varphi'$ — хотя бы $n+1$ нуль.</li>
<li>У $\varphi''$ — хотя бы $n$ нулей.</li>
<li>...</li>
<li>У $\varphi^{(n+1)}$ — хотя бы 1 нуль.</li>
</ul>
<p>Обозначим этот нуль через $\xi$.</p>
<p><strong>Шаг 4. Считаем $\varphi^{(n+1)}$.</strong></p>
<ul>
<li>$f^{(n+1)}(s)$ — производная порядка $n+1$ от $f$.</li>
<li>$P_n^{(n+1)}(s) = 0$ — производная многочлена степени $n$ обращается в ноль.</li>
<li>$\omega_{n+1}^{(n+1)}(s) = (n+1)!$ — у многочлена $\omega_{n+1}(s) = s^{n+1} + \text{(низшие)}$ старший коэффициент равен 1, поэтому $(n+1)$-я производная равна $(n+1)!$.</li>
</ul>
<p>Итого:
$$\varphi^{(n+1)}(s) = f^{(n+1)}(s) - K\cdot(n+1)!.$$</p>
<p><strong>Шаг 5.</strong> В точке $\xi$ это выражение равно нулю:
$$f^{(n+1)}(\xi) - K\cdot(n+1)! = 0 ;\Rightarrow; K = \frac{f^{(n+1)}(\xi)}{(n+1)!}.$$</p>
<p><strong>Шаг 6.</strong> Подставляем обратно в определение $K$:
$$\frac{f(t) - P_n(t)}{\omega_{n+1}(t)} = \frac{f^{(n+1)}(\xi)}{(n+1)!} ;\Rightarrow; f(t) - P_n(t) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\cdot \omega_{n+1}(t). \quad\blacksquare$$</p>
<h2>Что говорить на экзамене</h2>
<blockquote>
<p><strong>Задача интерполяции:</strong> найти $P_n(t)$ степени $\le n$ с $P_n(t_k) = f_k$. Такой многочлен существует и единствен.</p>
<p><strong>Лагранж:</strong> $L_n(t) = \sum_k f_k, l_k(t)$, $l_k(t) = \prod_{j\ne k}\dfrac{t - t_j}{t_k - t_j}$.</p>
<p><strong>Ньютон:</strong> $N_n(t) = \sum_k f[t_0, \ldots, t_k]\prod_{j&lt;k}(t - t_j)$.</p>
<p><strong>Сходства:</strong> $L_n \equiv N_n$ — это разные формы одного многочлена.</p>
<p><strong>Различия:</strong> Ньютон удобен при добавлении узлов и при оценке ошибки; Лагранж удобен теоретически.</p>
<p><strong>Формула ошибки:</strong> $f(t) - P_n(t) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!}\omega_{n+1}(t)$, где $\omega_{n+1}(t) = \prod_k(t - t_k)$.</p>
<p><strong>Доказательство:</strong> ввести $\varphi(s) = f(s) - P_n(s) - K\omega_{n+1}(s)$ с $K = (f(t)-P_n(t))/\omega_{n+1}(t)$; у $\varphi$ есть $n+2$ нуля (узлы + точка $t$); по Ролю у $\varphi^{(n+1)}$ есть нуль $\xi$; вычисляем $\varphi^{(n+1)}(\xi) = f^{(n+1)}(\xi) - K(n+1)! = 0$; отсюда $K$.</p>
</blockquote>

<h1>11. Конечные и разделённые разности; доказательство, что многочлен Ньютона — интерполяционный</h1>
<blockquote>
<p><strong>Источник:</strong> НОУ ИНТУИТ, лекция 7, разд. о разделённых разностях и многочлене Ньютона.</p>
</blockquote>
<h2>Зачем это нужно?</h2>
<p>Чтобы <strong>посчитать</strong> многочлен Ньютона, нужны его коэффициенты — <strong>разделённые разности</strong>. Также эти разности — самостоятельный важный объект: они появляются в численном дифференцировании, многошаговых методах, теории сплайнов.</p>
<h2>Конечные разности (для равномерной сетки)</h2>
<p>Пусть сетка равномерная: $t_k = t_0 + kh$.</p>
<p><strong>Разность 1-го порядка:</strong>
$$\Delta f_k = f_{k+1} - f_k.$$</p>
<p><strong>Разность $n$-го порядка</strong> (рекурсивно):
$$\Delta^n f_k = \Delta^{n-1} f_{k+1} - \Delta^{n-1} f_k.$$</p>
<p><strong>Явная формула</strong> (доказывается по индукции):
$$\boxed{;\Delta^n f_k = \sum_{j=0}^{n} (-1)^{n-j} \binom{n}{j} f_{k+j}.;}$$</p>
<p><strong>Связь с производной.</strong> Если $f$ гладкая:
$$\Delta f_k = f(t_{k+1}) - f(t_k) \approx h, f'(t_k) + \tfrac{h^2}{2}f''(t_k) + \ldots$$
По индукции:
$$\Delta^n f_k \approx h^n, f^{(n)}(t_k) + O(h^{n+1}).$$</p>
<p>То есть $\Delta^n f_k / h^n$ — приближение $n$-й производной.</p>
<h2>Разделённые разности (для произвольной сетки)</h2>
<p><strong>Разделённая разность 0-го порядка:</strong>
$$f[t_k] = f(t_k).$$</p>
<p><strong>Разделённая разность 1-го порядка:</strong>
$$f[t_k, t_{k+1}] = \frac{f[t_{k+1}] - f[t_k]}{t_{k+1} - t_k} = \frac{f_{k+1} - f_k}{t_{k+1} - t_k}.$$</p>
<p>(Это «приближённая производная» — отношение приращения функции к приращению аргумента.)</p>
<p><strong>Разделённая разность $m$-го порядка</strong> (рекурсивно):
$$\boxed{;f[t_k, t_{k+1}, \ldots, t_{k+m}] = \frac{f[t_{k+1}, \ldots, t_{k+m}] - f[t_k, \ldots, t_{k+m-1}]}{t_{k+m} - t_k}.;}$$</p>
<p><strong>Свойства.</strong></p>
<ol>
<li>
<p><strong>Симметричность по узлам.</strong> $f[t_0, t_1, \ldots, t_m]$ — симметричная функция от своих аргументов; от перестановки узлов значение не меняется. (Доказывается явной формулой $f[t_0, \ldots, t_m] = \sum_k \dfrac{f_k}{\prod_{j\ne k}(t_k - t_j)}$.)</p>
</li>
<li>
<p><strong>Связь с конечными разностями</strong> на равномерной сетке:
$$f[t_0, t_1, \ldots, t_n] = \frac{\Delta^n f_0}{n!, h^n}.$$</p>
</li>
<li>
<p><strong>Связь с производной.</strong> Если $f \in C^n$, то существует $\eta$ из выпуклой оболочки узлов такое, что
$$f[t_0, \ldots, t_n] = \frac{f^{(n)}(\eta)}{n!}.$$</p>
</li>
</ol>
<h2>Многочлен Ньютона как интерполяционный</h2>
<p><strong>Определение.</strong> Многочлен Ньютона:
$$N_n(t) = f[t_0] + f[t_0, t_1](t - t_0) + f[t_0, t_1, t_2](t - t_0)(t - t_1) + \ldots$$
$$\ldots + f[t_0, \ldots, t_n]\prod_{j=0}^{n-1}(t - t_j).$$</p>
<p><strong>Утверждение.</strong> $N_n(t)$ — это интерполяционный многочлен, то есть $N_n(t_k) = f_k$ для всех $k = 0, 1, \ldots, n$.</p>
<h2>Доказательство по индукции</h2>
<p><strong>База $n = 0$:</strong> $N_0(t) = f[t_0] = f_0$. Это константа, и $N_0(t_0) = f_0$. ✓</p>
<p><strong>Шаг индукции.</strong> Предположим, что $N_{n-1}(t)$ — интерполяционный многочлен на узлах $t_0, \ldots, t_{n-1}$, то есть $N_{n-1}(t_k) = f_k$ для $k = 0, \ldots, n-1$.</p>
<p>Запишем:
$$N_n(t) = N_{n-1}(t) + f[t_0, \ldots, t_n],\omega_n(t), \qquad \omega_n(t) = \prod_{j=0}^{n-1}(t - t_j).$$</p>
<p><strong>Проверка узлов $t_0, \ldots, t_{n-1}$:</strong> в этих точках $\omega_n(t_k) = 0$, значит $N_n(t_k) = N_{n-1}(t_k) = f_k$. ✓</p>
<p><strong>Проверка узла $t_n$:</strong> надо показать $N_n(t_n) = f_n$.</p>
<p>$$N_n(t_n) = N_{n-1}(t_n) + f[t_0, \ldots, t_n],\omega_n(t_n).$$</p>
<p>Перепишем определение разделённой разности через её значение в точках:
$$f[t_0, \ldots, t_n] = \frac{f_n - N_{n-1}(t_n)}{\omega_n(t_n)}.$$</p>
<p>(Это <strong>ключевое тождество</strong>, которое можно доказать отдельно: коэффициент при $t^n$ в интерполяционном многочлене Ньютона $N_n$ равен $f[t_0, \ldots, t_n]$ — это видно из определения. С другой стороны, многочлен $N_n - N_{n-1}$ имеет нули в $t_0, \ldots, t_{n-1}$, поэтому $N_n(t) - N_{n-1}(t) = c\cdot\omega_n(t)$ для некоторой константы $c$. Сравнивая с определением $N_n$, имеем $c = f[t_0, \ldots, t_n]$. С другой стороны, должно быть $N_n(t_n) = f_n$, отсюда $f[t_0, \ldots, t_n]\cdot \omega_n(t_n) = f_n - N_{n-1}(t_n)$.)</p>
<p>Подставляя обратно:
$$N_n(t_n) = N_{n-1}(t_n) + \frac{f_n - N_{n-1}(t_n)}{\omega_n(t_n)}\cdot \omega_n(t_n) = N_{n-1}(t_n) + (f_n - N_{n-1}(t_n)) = f_n. \quad\blacksquare$$</p>
<h2>Альтернативное доказательство через единственность</h2>
<p>Многочлен Ньютона $N_n$ — степени $\le n$ (явно по построению). Если в нём $n+1$ значение совпадает со значениями $f$ — он совпадает с <strong>единственным</strong> интерполяционным многочленом $L_n$ Лагранжа. Это даёт ту же мысль немного иначе.</p>
<h2>Что говорить на экзамене</h2>
<blockquote>
<p><strong>Конечные разности:</strong> $\Delta^n f_k = \sum_j (-1)^{n-j}\binom{n}{j}f_{k+j}$. Связь с производной: $\Delta^n f \approx h^n f^{(n)}$.</p>
<p><strong>Разделённые разности:</strong> $f[t_k, \ldots, t_{k+m}] = \dfrac{f[t_{k+1}, \ldots, t_{k+m}] - f[t_k, \ldots, t_{k+m-1}]}{t_{k+m} - t_k}$. Симметричны по узлам; на равномерной сетке $= \Delta^n f_0/(n!,h^n)$; для гладкой $f$ равны $f^{(n)}(\eta)/n!$.</p>
<p><strong>Многочлен Ньютона:</strong> $N_n(t) = \sum_{k=0}^n f[t_0,\ldots,t_k]\prod_{j&lt;k}(t - t_j)$.</p>
<p><strong>Доказательство интерполяционности (по индукции):</strong> $N_0(t_0) = f_0$ — база. Шаг: $N_n(t) = N_{n-1}(t) + f[t_0,\ldots,t_n]\omega_n(t)$. В узлах $t_0,\ldots,t_{n-1}$ имеем $\omega_n(t_k) = 0$, значит $N_n(t_k) = N_{n-1}(t_k) = f_k$. В $t_n$ — по определению разделённой разности $f[t_0,\ldots,t_n]$, добавочный член «доводит» $N_{n-1}(t_n)$ до $f_n$.</p>
</blockquote>
