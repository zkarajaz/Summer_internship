# Тема 6. Задание №2: Статическая память
## Описание
Создайте функцию, которая подсчитывает, сколько раз её вызвали. Для этого используйте модификатор `static` для локальной переменной-счетчика.
## Теория
[cppreference: Storage duration](https://en.cppreference.com/w/c/language/storage_duration)
Статические переменные инициализируются один раз при старте программы и сохраняют значение между вызовами функции.
## Требования к решению
1. Использовать `static int counter = 0;` внутри функции.
2. Вызвать функцию трижды из `main`.
## Тестовые примеры
Запуск: `./a.out`
Вывод:
Call 1
Call 2
Call 3
## Описание решения
Без `static` переменная `counter` создавалась бы заново (в стеке) при каждом вызове и всегда была бы равна 1.
