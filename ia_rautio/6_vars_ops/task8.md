# Тема 6. Задание №8: Деление и приведение
## Описание
В C результат деления двух целых чисел всегда целое число (дробная часть отбрасывается). Напишите программу, которая правильно вычисляет `5 / 2 = 2.5`, используя явное приведение одного из операндов к типу `float`.
## Теория
[cppreference: Implicit conversions](https://en.cppreference.com/w/c/language/conversion)
Если один из операндов — `float`, второй автоматически повышается до `float` перед делением.
## Требования к решению
1. Использовать переменные `int a = 5, b = 2`.
2. Выполнить `(float)a / b`.
## Тестовые примеры
Запуск: `./a.out`
Вывод:
Integer division: 2
Floating division: 2.5
## Описание решения
Без приведения `5 / 2` даст `2`. С явным приведением `(float)5 / 2` мы получаем корректные `2.5`.
