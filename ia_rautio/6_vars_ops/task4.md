# Тема 6. Задание №4: Короткое замыкание
## Описание
Логические операторы `&&` (И) и `||` (ИЛИ) в C работают по принципу "short-circuit evaluation". Если результат ясен по первой части выражения, вторая часть не вычисляется. Проверьте это, поставив инкремент переменной во вторую часть условия.
## Теория
[cppreference: Logical operators](https://en.cppreference.com/w/c/language/operator_logical)
## Требования к решению
1. Условие `if (0 && ++a)`.
2. Проверить, изменилось ли значение `a`.
## Тестовые примеры
Запуск: `./a.out`
Вывод: `a is still 0`
## Описание решения
Так как левая часть `&&` равна 0 (Ложь), всё выражение ложно. Процессор даже не пытается вычислить `++a`, поэтому переменная не меняется.
