# Тема 7. Задание №6: Группировка case
## Описание
Продемонстрируйте возможность группировки нескольких меток `case` для выполнения одного и того же действия. Напишите программу, которая по номеру дня недели (1-7) выводит, рабочий это день или выходной.
## Теория
[cppreference: switch statement](https://en.cppreference.com/w/c/language/switch)
Если между `case` нет оператора `break`, выполнение продолжается до следующего `break`. Это позволяет объединять логические группы.
## Требования к решению
1. Использовать `switch`.
2. Сгруппировать `case 1-5` для "Workday" и `case 6-7` для "Weekend".
## Тестовые примеры
Вход: 1 -> Вывод: "Workday"
Вход: 6 -> Вывод: "Weekend"
## Описание решения
Метки `case 1`, `case 2` и т.д. идут подряд без кода и `break`, поэтому при попадании в любую из них управление приводит к общему `printf`.
