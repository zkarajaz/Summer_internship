# Тема 7. Задание №8: Типы в switch
## Описание
Попытайтесь использовать вещественное число (`double`) в качестве условия для `switch`. Убедитесь, что это вызывает ошибку компиляции, и объясните почему.
## Теория
[cppreference: switch statement limits](https://en.cppreference.com/w/c/language/switch)
В языке C оператор `switch` работает только с целочисленными типами (`int`, `char`, `enum`). Это связано с тем, что компилятор строит таблицу переходов, которая требует точных целочисленных индексов.
## Требования к решению
1. Написать код с `switch(3.14)`.
## Тестовые примеры
Компиляция: `gcc task8.c`
Вывод: `error: switch quantity not an integer`
## Описание решения
Компилятор не позволяет использовать `float/double`, так как сравнение вещественных чисел на равенство (которое нужно для case) не является точным.
