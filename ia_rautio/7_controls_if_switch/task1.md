# Тема 7. Задание №1: Простой if-else
## Описание
Напишите программу, которая проверяет, является ли введенное число четным и положительным одновременно.
## Теория
[cppreference: if statement](https://en.cppreference.com/w/c/language/if)
Оператор `if` выполняет блок кода, если условие истинно (не равно 0).
## Требования к решению
1. Ввести число.
2. Использовать `if` с логическим И (`&&`).
## Тестовые примеры
Вход: 4 -> Вывод: "Yes"
Вход: -2 -> Вывод: "No"
## Описание решения
Простое условие `(n > 0 && n % 2 == 0)` проверяет оба критерия сразу.
