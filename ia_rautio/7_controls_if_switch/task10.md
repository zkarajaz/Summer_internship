# Тема 7. Задание №10: Роль default
## Описание
Реализуйте простейший калькулятор на 4 операции (+, -, *, /). Используйте блок `default` для обработки ситуации, когда пользователь ввел неизвестный символ операции.
## Теория
[cppreference: switch default](https://en.cppreference.com/w/c/language/switch)
Блок `default` выполняется в том случае, если ни одна из меток `case` не совпала с условием. Это важно для обработки ошибок ввода.
## Требования к решению
1. Проверить операцию через `switch(char)`.
2. Вывести сообщение об ошибке в `default`.
## Тестовые примеры
Вход: '?' -> Вывод: "Error: Unknown operation"
## Описание решения
Если введенный символ не '+', '-', '*' или '/', управление переходит в `default`, предотвращая непредсказуемое поведение программы.
