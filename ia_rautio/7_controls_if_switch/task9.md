# Тема 7. Задание №9: Область видимости в case
## Описание
Попробуйте объявить и инициализировать переменную прямо внутри блока `case`. Продемонстрируйте ошибку компиляции и способ её решения с помощью фигурных скобок `{}`.
## Теория
[Scope in switch cases](https://en.cppreference.com/w/c/language/switch)
Метка `case` — это лишь адрес в коде. В C нельзя объявлять переменную сразу после метки без создания нового блока кода, так как это нарушает правила инициализации.
## Требования к решению
1. Показать код, который падает без `{}`.
2. Исправить его, обернув содержимое `case` в `{}`.
## Тестовые примеры
Запуск: `./a.out`
Вывод: `X = 10`
## Описание решения
Добавление `{}` создает локальную область видимости внутри `case`, что позволяет безопасно объявлять там переменные.
