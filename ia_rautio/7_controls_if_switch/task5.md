# Тема 7. Задание №5: Базовый switch
## Описание
Напишите программу, которая по номеру дня недели (1-7) выводит его название, используя `switch`.
## Теория
[cppreference: switch statement](https://en.cppreference.com/w/c/language/switch)
`switch` работает быстрее `if-else`, так как компилятор часто создает "таблицу переходов" (jump table).
## Требования к решению
1. Использовать `switch` и `case`.
2. Не забыть `break` в каждом блоке.
## Тестовые примеры
Вход: 3 -> Вывод: "Wednesday"
## Описание решения
Для каждого числа прописан свой `case`. Если `break` опущен, выполнение "провалится" в следующий `case`.
