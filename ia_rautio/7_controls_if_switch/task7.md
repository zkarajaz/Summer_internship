# Тема 7. Задание №7: Трюк с Fallthrough (Накопление)
## Описание
Продемонстрируйте, как отсутствие `break` (fallthrough) может быть полезной функцией, а не ошибкой в логике. Реализуйте систему уровней доступа: "Admin" получает права админа + модератора + юзера; "Mod" получает права модератора + юзера; "User" — только юзера.
## Теория
[Switch Fallthrough](https://en.wikipedia.org/wiki/Switch_statement#Fallthrough)
Умышленное отсутствие `break` позволяет реализовывать иерархическую или накопительную логику.
## Требования к решению
1. Использовать `enum` для ролей.
2. В `switch` не использовать `break` между ролями, чтобы права суммировались.
## Тестовые примеры
Вход: ADMIN -> Вывод: "Admin rights, Moderator rights, User rights"
## Описание решения
При выборе `ADMIN` выполняются все блоки `printf` по очереди, так как выполнение "проваливается" вниз сквозь все уровни.
