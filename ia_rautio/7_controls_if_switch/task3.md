# Тема 7. Задание №3: Каскад else if
## Описание
Напишите систему перевода баллов в оценку: 90+ (5), 80-89 (4), 70-79 (3), остальные (2).
## Теория
[cppreference: if statement](https://en.cppreference.com/w/c/language/if)
Конструкция `else if` позволяет проверять несколько исключающих друг друга условий по порядку.
## Требования к решению
1. Использовать каскад условий.
## Тестовые примеры
Вход: 85 -> Вывод: "Grade: 4"
## Описание решения
Программа проверяет условия сверху вниз. Как только одно истинно, остальные игнорируются.
