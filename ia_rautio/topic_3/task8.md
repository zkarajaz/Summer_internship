# Тема 3. Задание №8: Умная оптимизация
## Описание
Продемонстрируйте мощь оптимизатора GCC. Напишите программу с бесполезным циклом на 1 миллиард итераций. Сравните время выполнения при компиляции без оптимизации (`-O0`) и с максимальной оптимизацией (`-O3`), где компилятор должен догадаться вырезать цикл.
## Теория
[GCC: Optimize Options](https://gcc.gnu.org/onlinedocs/gcc/Optimize-Options.html)
## Требования к решению
1. Использовать цикл `for` на `1000000000` итераций.
2. Замерять время выполнения с помощью утилиты `time`.
3. Показать разницу во времени для сборок с `-O0` и `-O3`.
## Тестовые примеры
Запуск 1 (без оптимизации): `gcc -O0 task8.c && time ./a.out`
Вывод:
real    0m1.850s
user    0m1.845s
sys     0m0.000s

Запуск 2 (с оптимизацией): `gcc -O3 task8.c && time ./a.out`
Вывод:
real    0m0.001s
user    0m0.000s
sys     0m0.001s
## Описание решения
Компилятор с флагом `-O3` анализирует код, понимает, что цикл не влияет на результат программы (является "мертвым кодом"), и полностью удаляет его, что приводит к почти мгновенному выполнению.
