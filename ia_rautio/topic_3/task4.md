# Тема 3. Задание №4: Этап ассемблирования (-S)
## Описание
Используя флаг `-S`, преобразуйте исходный код на C в текстовый файл с командами ассемблера для вашей архитектуры процессора.
## Теория
[GCC: Overall Options](https://gcc.gnu.org/onlinedocs/gcc/Overall-Options.html)
Ассемблерный код — это низкоуровневое представление программы, где каждая инструкция соответствует одной операции процессора (например, `mov`, `add`, `ret`).
## Требования к решению
1. Сгенерировать файл `.s` с помощью флага `-S`.
2. Прочитать содержимое файла командой `cat`.
## Тестовые примеры
Команда: `gcc -S task4.c && cat task4.s`
Вывод:
main:
    pushq   %rbp
    movq    %rsp, %rbp
    movl    $42, %eax
    popq    %rbp
    ret
## Описание решения
Флаг `-S` создает файл `task4.s`, содержащий ассемблерные инструкции, которые понятны процессору.
