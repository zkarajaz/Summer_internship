# Тема 3. Задание №3: Этап препроцессора (-E)
## Описание
Продемонстрируйте работу препроцессора. Используйте флаг `-E`, чтобы увидеть код после раскрытия макросов `#define`, но до начала компиляции в машинный код.
## Теория
[GCC: Preprocessor Options](https://gcc.gnu.org/onlinedocs/gcc/Preprocessor-Options.html)
Препроцессор выполняет текстовые замены (макросы, вставка файлов `#include`) и удаляет комментарии.
## Требования к решению
1. Создать макрос `#define VALUE 100`.
2. Запустить компиляцию с флагом `-E`.
3. Найти в выводе терминала строку, где макрос заменен числом.
## Тестовые примеры
Команда: `gcc -E task3.c | tail -n 5`
Вывод:
int main(void) {
    return 100;
}
## Описание решения
Флаг `-E` заставляет GCC остановиться после этапа препроцессирования. Мы видим "чистый" C-код, готовый для трансляции в ассемблер.
