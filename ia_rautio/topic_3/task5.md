# Тема 3. Задание №5: Макрос извне
## Описание
Напишите программу, поведение которой можно изменить в момент компиляции, не трогая исходный код. Если задан макрос `DEBUG`, программа должна выводить "Debug mode", иначе — "Release mode".
## Теория
[GCC: Preprocessor Options](https://gcc.gnu.org/onlinedocs/gcc/Preprocessor-Options.html)
## Требования к решению
1. Использовать директивы препроцессора `#ifdef` / `#else` / `#endif`.
2. При компиляции передавать макрос через флаг `-DDEBUG`.
## Описание решения
Флаг `-D` определяет макрос так, как если бы в коде была написана строка `#define DEBUG 1`.
