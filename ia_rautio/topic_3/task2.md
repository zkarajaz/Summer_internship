# Тема 3. Задание №2: Имя бинарного файла (-o)
## Описание
По умолчанию GCC называет исполняемый файл `a.out`. Используя флаг `-o`, скомпилируйте программу так, чтобы итоговый файл назывался `my_prog`.
## Теория
[GCC: Overall Options](https://gcc.gnu.org/onlinedocs/gcc/Overall-Options.html)
Флаг `-o <file>` позволяет задать имя выходного файла на любом этапе сборки.
## Требования к решению
1. Скомпилировать файл с флагом `-o my_prog`.
2. Запустить файл командой `./my_prog`.
## Тестовые примеры
Сборка: `gcc task2.c -o my_prog`
Запуск: `./my_prog`
Вывод: `Custom output name works!`
## Описание решения
Команда `gcc task2.c -o my_prog` создает бинарный файл `my_prog` вместо стандартного `a.out`.
