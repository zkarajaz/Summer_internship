# Тема 4. Задание №1: Предел int
## Описание
Подключите заголовочный файл `<limits.h>` для доступа к макросу `INT_MAX`, который содержит максимальное значение для типа `int`. Продемонстрируйте целочисленное переполнение (integer overflow), прибавив к этому значению единицу.
## Теория
[cppreference: Fixed width integer types/limits](https://en.cppreference.com/w/c/types/limits)
## Требования к решению
1. Включить `<limits.h>` и `<stdio.h>`.
2. Создать переменную, равную `INT_MAX`.
3. Вывести на экран результат `INT_MAX + 1`.
## Тестовые примеры
Запуск: `./a.out`
Вывод: `INT_MAX: 2147483647, INT_MAX + 1: -2147483648`
## Описание решения
При переполнении знакового целого числа происходит переход от максимального положительного значения к минимальному отрицательному.
