# Тема 4. Задание №4: Литералы
## Описание
По умолчанию целочисленные константы (литералы) в коде имеют тип `int`. Если число не помещается в `int`, компилятор может выдать предупреждение или ошибку. Продемонстрируйте использование суффиксов `LL` (для `long long`) и `U` (для `unsigned`), чтобы явно указать тип большого числового литерала.
## Теория
[cppreference: Integer constant](https://en.cppreference.com/w/c/language/integer_constant)
## Требования к решению
1. Создать переменную типа `long long` и присвоить ей большое число с суффиксом `LL`.
2. Создать переменную `unsigned int` с суффиксом `U`.
3. Вывести значения переменных, используя корректные спецификаторы формата.
## Тестовые примеры
Запуск: `./a.out`
Вывод:
A very big number: 9223372036854775807
An unsigned number: 4000000000
## Описание решения
Суффиксы `L`, `LL`, `U` позволяют компилятору правильно интерпретировать тип числовых констант в коде, избегая переполнений на этапе компиляции.
