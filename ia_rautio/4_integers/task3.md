# Тема 4. Задание №3: Магия unsigned
## Описание
Продемонстрируйте особенность арифметики беззнаковых (unsigned) целых чисел. Создайте переменную `unsigned int`, равную 0, и вычтите из нее 1. Выведите результат.
## Теория
[cppreference: Unsigned integer wrapping](https://en.cppreference.com/w/c/language/arithmetic_types#Unsigned_integer_wrapping)
## Требования к решению
1. Использовать тип `unsigned int`.
2. Выполнить операцию вычитания.
3. Вывести результат со спецификатором `%u`.
## Тестовые примеры
Запуск: `./a.out`
Вывод: `0 - 1 = 4294967295`
## Описание решения
Арифметика беззнаковых чисел работает по модулю `2^N`. Вычитание 1 из 0 приводит к "переносу" к максимальному возможному значению.
