# Тема 4. Задание №9: enum под капотом
## Описание
Перечисления (`enum`) в C — это способ дать имена целочисленным константам. По стандарту, базовый тип `enum` должен быть совместим с `int`. Проверьте это, выведя размер простого перечисления с помощью `sizeof`.
## Теория
[cppreference: enum declaration](https://en.cppreference.com/w/c/language/enum)
## Требования к решению
1. Создать простое перечисление `enum Color`.
2. Использовать `sizeof(enum Color)` для определения его размера.
## Тестовые примеры
Запуск: `./a.out`
Вывод: `Size of enum Color: 4 bytes`
## Описание решения
Поскольку `enum` совместим с `int`, его размер на большинстве платформ будет равен размеру `int`, то есть 4 байтам.
