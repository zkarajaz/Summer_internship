# Тема 4. Задание №7: Точные размеры
## Описание
Размеры типов `int` и `long` могут отличаться на разных системах (например, 32-битных и 64-битных). Для написания переносимого кода стандарт C99 ввел заголовочный файл `<stdint.h>`, который предоставляет типы с гарантированным размером. Продемонстрируйте объявление переменных с типами `int32_t` и `uint64_t`.
## Теория
[cppreference: Fixed width integer types](https://en.cppreference.com/w/c/types/integer)
## Требования к решению
1. Подключить заголовочный файл `<stdint.h>`.
2. Объявить переменную `int32_t` (знаковое 32-битное целое).
3. Объявить переменную `uint64_t` (беззнаковое 64-битное целое).
4. Вывести размеры этих типов, чтобы убедиться, что они соответствуют 4 и 8 байтам.
## Тестовые примеры
Запуск: `./a.out`
Вывод:
Size of int32_t: 4 bytes
Size of uint64_t: 8 bytes
## Описание решения
Типы из `stdint.h` (например, `int8_t`, `uint16_t`) критически важны в системном программировании, работе с сетевыми протоколами и форматами файлов, где размер каждого бита имеет значение.
