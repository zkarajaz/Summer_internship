# Тема 5. Задание №1: Основы float и double
## Описание
Напишите программу, которая объявляет переменную типа `float` и `double`, присваивает им значения с плавающей точкой и выводит их на экран с ограничением до двух знаков после запятой.
## Теория
[cppreference: Floating point types](https://en.cppreference.com/w/c/language/arithmetic_types#Floating-point_types)
Тип `float` обычно занимает 4 байта, а `double` — 8 байт.
## Требования к решению
1. Использовать спецификатор `%.2f` для вывода.
2. Использовать суффикс `f` для инициализации переменной типа `float`.
## Тестовые примеры
Запуск: `./a.out`
Вывод:
Float value: 3.14
Double value: 2.72
## Описание решения
Используются базовые типы данных `float` и `double` и форматированный вывод `printf`.
