# Тема 5. Задание №5: Не число (NaN)
## Описание
Значение `NaN` (Not a Number) возникает при неопределенных математических операциях, например, делении нуля на ноль. Продемонстрируйте генерацию `NaN` и проверку этого значения с помощью `isnan()`.
## Теория
[cppreference: isnan](https://en.cppreference.com/w/c/numeric/math/isnan)
Особенность `NaN` в том, что он не равен ничему, даже самому себе (`NaN != NaN`).
## Требования к решению
1. Сгенерировать `NaN` через `0.0 / 0.0`.
2. Вывести результат.
3. Проверить через `isnan()`.
## Тестовые примеры
Запуск: `./a.out`
Вывод:
Value: nan
Is it NaN? Yes
## Описание решения
Любая арифметическая операция с `NaN` также дает в результате `NaN`.
