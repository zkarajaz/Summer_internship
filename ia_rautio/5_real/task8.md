# Тема 5. Задание №8: Библиотека math.h
## Описание
Вычислите квадратный корень из числа 2.0. Обратите внимание, что при использовании математических функций в Linux компилятору GCC нужно явно указать флаг `-lm` для линковки математической библиотеки.
## Теория
[man math.h](https://man7.org/linux/man-pages/man7/math.h.7.html)
Функции `sqrt`, `pow`, `sin` требуют подключения `<math.h>` и флага `-lm` при компиляции.
## Требования к решению
1. Использовать функцию `sqrt()`.
2. Продемонстрировать команду сборки с флагом `-lm`.
## Тестовые примеры
Сборка: `gcc task8.c -lm`
Запуск: `./a.out`
Вывод: `Square root of 2.0 is 1.414214`
## Описание решения
Программа вызывает функцию из внешней библиотеки `libm`. Без флага `-lm` линкер выдаст ошибку "undefined reference to `sqrt`".
