# Тема 5. Задание №10: Экстремальная точность
## Описание
В языке C существует тип `long double` для вычислений с максимальной точностью, которую поддерживает процессор (обычно 80 или 128 бит). Узнайте его размер и выведите значение числа Пи с повышенной точностью.
## Теория
[cppreference: Floating point types](https://en.cppreference.com/w/c/language/arithmetic_types)
Для вывода `long double` используется спецификатор `%Lf`, а для литералов — суффикс `L`.
## Требования к решению
1. Использовать тип `long double` и литерал с суффиксом `L`.
2. Вывести размер через `sizeof`.
## Тестовые примеры
Запуск: `./a.out`
Вывод:
Size of long double: 16 bytes (может быть 12)
Pi (long double): 3.141592653589793238
## Описание решения
`long double` обеспечивает больше значащих цифр, чем `double`, что критично для научных расчетов.
