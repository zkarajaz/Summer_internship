# Тема 2. Задание №5: Переменные окружения
## Описание
Используя третий аргумент функции main `char *envp[]`, напишите программу, которая ищет в переменных окружения строку, начинающуюся с "USER=", и выводит её на экран. Не используйте готовую функцию `getenv()`.
## Теория
[GNU libc manual: Program Arguments (envp)](https://www.gnu.org/software/libc/manual/html_node/Program-Arguments.html)
## Требования к решению
1. Использовать сигнатуру `int main(int argc, char *argv[], char *envp[])`
2. Перебрать массив `envp` в цикле, пока не будет встречен `NULL`.
3. С помощью `strncmp` найти нужную переменную.
## Описание решения
Цикл `while (*envp)` проходит по всем переменным. `strncmp(*envp, "USER=", 5) == 0` сравнивает первые 5 символов каждой строки.
