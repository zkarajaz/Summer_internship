# Тема 2. Задание №7: Стиль BusyBox
## Описание
Продемонстрируйте подход, используемый в утилите `BusyBox`: один бинарный файл выполняет разные действия в зависимости от того, под каким именем его запустили. Программа должна проверять `argv[0]`: если в имени есть слово "add", она складывает два числа; если "mul" — умножает.
## Теория
[cppreference: string/byte/strstr](https://en.cppreference.com/w/c/string/byte/strstr)
## Требования к решению
1. Создать символические ссылки `add` и `mul` на скомпилированный бинарник.
2. Использовать `strstr()` для поиска подстроки в `argv[0]`.
3. Аргументы для вычислений брать из `argv[1]` и `argv[2]`, преобразуя их в числа с помощью `atoi()`.
## Описание решения
Программа анализирует `argv[0]`. Если находит "add", выполняет сложение. Если "mul" — умножение. `atoi()` из `stdlib.h` конвертирует строки в `int`.
