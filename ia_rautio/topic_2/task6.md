# Тема 2. Задание №6: Подсчет переменных
## Описание
Напишите программу, которая подсчитывает и выводит общее количество переменных окружения, переданных программе. Массив `envp` заканчивается `NULL`-указателем.
## Теория
[GNU libc manual: Program Arguments (envp)](https://www.gnu.org/software/libc/manual/html_node/Program-Arguments.html)
## Требования к решению
1. Использовать цикл, который считает строки в `envp` до `NULL`.
2. Вывести итоговое число.
## Описание решения
Счетчик `count` инкрементируется в цикле `while`, пока `envp[count]` не станет `NULL`.
