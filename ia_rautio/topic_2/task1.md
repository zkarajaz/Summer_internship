# Тема 2. Задание №1: Стандартный возврат
## Описание
Напишите минимально необходимую программу на C с функцией `main`, которая ничего не делает и успешно завершается, возвращая операционной системе код `0`.
## Теория
[cppreference: main function](https://en.cppreference.com/w/c/language/main_function)
## Требования к решению
1. Сигнатура `int main(void)`
2. В теле функции должна быть только инструкция `return 0;`
## Описание решения
Код представляет собой минимальную точку входа в программу.
