# Тема 2. Задание №3: Подсчет аргументов
## Описание
Напишите программу, которая выводит количество переданных ей аргументов командной строки (включая имя самой программы).
## Теория
[Command-line arguments](https://en.cppreference.com/w/c/language/main_function.html)
## Требования к решению
1. Использовать сигнатуру `int main(int argc, char *argv[])`
2. Вывести на экран значение `argc`.
## Описание решения
Программа получает количество аргументов в `argc` и выводит его с помощью `printf`.
