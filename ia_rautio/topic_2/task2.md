# Тема 2. Задание №2: Нестандартный возврат
## Описание
Модифицируйте программу из прошлого задания так, чтобы она возвращала код `69`. Скомпилируйте, запустите и проверьте, что операционная система действительно получила этот код.
## Теория
[Process Termination](https://en.cppreference.com/w/c/program/exit)
## Требования к решению
1. Функция `main` должна возвращать целое число `69`
2. Для проверки использовать команду `echo $?`, которая выводит код возврата последней выполненной программы.

## Описание решения
- `return 69;`
- Команда проверки: `echo $?`
