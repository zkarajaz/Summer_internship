# Тема 2. Задание №8: Стандартные коды
## Описание
Для лучшей портируемости кода (совместимости с разными ОС) вместо `return 0` и `return 1` рекомендуется использовать макросы `EXIT_SUCCESS` и `EXIT_FAILURE` из `stdlib.h`. Напишите программу, которая возвращает `EXIT_FAILURE`, если ей не передали ни одного аргумента командной строки (кроме имени).
## Теория
[cppreference: EXIT_SUCCESS, EXIT_FAILURE](https://en.cppreference.com/w/c/program/EXIT_status)
## Описание решения
Программа проверяет `argc` и в зависимости от него возвращает один из стандартных макросов.
