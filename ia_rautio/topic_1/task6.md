# Тема 1. Задание №6: Короткая схема
## Описание
С помощью логического И (`&&`) напишите цепочку команд в одну строку: создать папку `temp_dir`, зайти в нее и вывести сообщение об успехе. Если создание директории не удалось (например, нет прав), последующие команды (`cd` и `echo`) выполняться не должны.
## Теория
[GNU Bash: Lists of Commands](https://www.gnu.org/software/bash/manual/html_node/Lists.html)
## Требования к решению
1. Использовать команды 'mkdir', 'cd', 'echo'
2. Связать их оператором '&&'
## Описание решения
- mkdir temp_dir && cd temp_dir && echo "Success! Inside $(pwd)"
