# Тема 1. Задание №2: Код возврата
## Описание
Любая команда в Linux возвращает код завершения (0 — успех, не 0 — ошибка). Требуется запустить невалидную команду (попытка вывести содержимое несуществующей директории) и вывести код её возврата.
## Теория
[GNU Bash: Special Parameters](https://www.gnu.org/software/bash/manual/html_node/Special-Parameters.html)
## Требования к решению
1. Использовать специальную переменную '$?'
2. Вывести полученный код в терминал.
## Описание решения
- ls /fake_dir
- echo "Exit code: $?"
