# Тема 1. Задание №7: Значение по умолчанию
## Описание
Часто в скриптах нужно использовать переменную окружения (например, `$EDITOR`), но она может быть не задана пользователем. Продемонстрируйте механизм Bash "Parameter Expansion", который подставляет значение по умолчанию (`nano`), если переменная пуста или не существует.
## Теория
[GNU Bash: Parameter Expansion](https://www.gnu.org/software/bash/manual/html_node/Shell-Parameter-Expansion.html)
## Требования к решению
1. Использовать конструкцию `${VAR:-default}`
2. Вывести результат в терминал с помощью `echo`
## Описание решения
- echo "System editor is: ${EDITOR:-nano}"
