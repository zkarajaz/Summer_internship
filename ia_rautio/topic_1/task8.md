# Тема 1. Задание №8: Подстановка команд
## Описание
Сгенерируйте динамическую строку, в которую вложен результат выполнения других команд. Используйте оператор `$()` для того, чтобы подставить имя текущего пользователя (`whoami`) и текущую директорию (`pwd`) прямо в команду `echo`.
## Теория
[GNU Bash: Command Substitution](https://www.gnu.org/software/bash/manual/html_node/Command-Substitution.html)
## Требования к решению
1. Использовать синтаксис '$()'
2. Вызвать внутри строки команды 'whoami' и 'pwd'
## Описание решения
- echo "User $(whoami) is currently in $(pwd)"
