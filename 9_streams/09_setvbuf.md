# 09. Изменение режима буферизации: setvbuf

**Сложность:** простая

**Файл с решением:** [09_setvbuf.c](./09_setvbuf.c)

## Описание задачи

Сделайте `stdout` **небуферизованным** через `setvbuf(stdout, NULL, _IONBF, 0)` сразу после старта `main`. Затем напечатайте `tick` без `\n` и сделайте паузу — символы должны появиться немедленно, без `fflush`.

## Описание решения

`setvbuf` задаёт режим: `_IOFBF` (полная), `_IOLBF` (построчная), `_IONBF` (без буферизации). Полезно для журналирования, где важна немедленная видимость, ценой производительности.

Вывод:

             ← пауза 1 секунда
 done
