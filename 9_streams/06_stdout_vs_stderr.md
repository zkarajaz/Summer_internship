# 06. Разделение полезного вывода и логов

**Сложность:** простая

**Файл с решением:** [06_stdout_vs_stderr.c](./06_stdout_vs_stderr.c)

## Описание задачи

Программа считает квадрат числа 7 и печатает результат `49` в **stdout**. Параллельно она логирует диагностику `computing 7*7` в **stderr**. Запуск с `2>/dev/null` должен оставить только результат.

## Описание решения

В Unix принято: полезные данные программы идут в stdout (их можно «пайпить»), а ход выполнения, предупреждения и ошибки — в stderr. Тогда другие утилиты получат именно данные, а пользователь не пропустит проблему.

## Примеры

**Пример 1.**

```
$ ./a.out
computing 7*7
49
```

**Пример 2.**

```
$ ./a.out 2>/dev/null
49
```
