# 03. puts против printf

**Сложность:** супер простая

**Файл с решением:** [03_puts_vs_printf.c](./03_puts_vs_printf.c)

## Описание задачи

Выведите две одинаковые строки `Hello`: одну через `puts`, другую через `printf`. Сравните: `puts` короче и сам добавляет `\n`; `printf` мощнее, но дороже.

## Описание решения

Когда нужен только вывод неформатированной строки с переводом строки — `puts` предпочтительнее: проще и быстрее. `printf` нужен, если есть форматирование (`%d`, `%s` и т.д.).

## Примеры

**Пример 1.**

Вывод:
```
Hello
Hello
```
