# 02. Сообщение об ошибке в stderr

**Сложность:** супер простая

**Файл с решением:** [02_fprintf_stderr.c](./02_fprintf_stderr.c)

## Описание задачи

Выведите строку `error: file not found` в **stderr** с помощью `fprintf(stderr, ...)`. Проверьте, что её можно отделить от обычного вывода через перенаправление `2>err.txt`.

## Описание решения

`stderr` — отдельный поток для диагностики. Он не буферизован, его удобно отделять перенаправлением `2>` от обычного вывода в `stdout`.

## Примеры

**Пример 1.**

```
$ ./a.out
error: file not found
```

**Пример 2.**

```
$ ./a.out 2>err.txt
(на экране пусто; в файле err.txt: error: file not found)
```
