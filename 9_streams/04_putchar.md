# 04. Посимвольный вывод putchar

**Сложность:** супер простая

**Файл с решением:** [04_putchar.c](./04_putchar.c)

## Описание задачи

Выведите строку `abc\n` в stdout, используя только `putchar`.

## Описание решения

`putchar(c)` — самый дешёвый способ напечатать один символ. Полезен, когда не нужен формат-парсер `printf`.

## Примеры

**Пример 1.**

Вывод:
```
abc
```
