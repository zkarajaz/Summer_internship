# 08. perror для системных ошибок

**Сложность:** простая

**Файл с решением:** [08_perror.c](./08_perror.c)

## Описание задачи

Попробуйте открыть несуществующий файл `/no/such/file` через `fopen`. Если результат `NULL`, вызовите `perror("fopen")`. На выходе должно быть что-то вроде `fopen: No such file or directory`.

## Описание решения

`perror(prefix)` печатает в `stderr` префикс, двоеточие и человекочитаемое описание текущей ошибки (`errno`). Это короче и надёжнее, чем самому форматировать сообщение.

Вывод:
