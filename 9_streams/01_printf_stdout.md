# 01. Вывод в stdout через printf

**Сложность:** супер простая

**Файл с решением:** [01_printf_stdout.c](./01_printf_stdout.c)

## Описание задачи

Выведите строку `stdout works` на стандартный поток вывода с помощью `printf`.

## Описание решения

`printf` пишет в `stdout` — стандартный поток вывода. По умолчанию он буферизован построчно при выводе на терминал.

## Примеры

**Пример 1.**

Вывод:
```
stdout works
```
