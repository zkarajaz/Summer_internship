# 10. Безопасный ввод строки: fgets вместо gets

**Сложность:** простая

**Файл с решением:** [10_fgets_safe_input.c](./10_fgets_safe_input.c)

## Описание задачи

Прочитайте строку до 63 символов в буфер `char buf[64]` через `fgets(buf, sizeof buf, stdin)` и распечатайте её обратно. **Не используйте `gets`** — он удалён из стандарта C11 как небезопасный (нет проверки длины).

## Описание решения

`fgets` принимает максимальную длину буфера и поэтому защищён от переполнения. Возвращает `NULL` при EOF/ошибке. `gets` не имеет такого аргумента и приводит к buffer overflow при длинном вводе — поэтому он удалён в C11.

## Примеры

**Пример 1.**

Ввод (stdin):
```
привет
```

Вывод:
```
вы ввели: привет
```
