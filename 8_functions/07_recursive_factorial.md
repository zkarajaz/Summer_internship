# 07. Рекурсивная функция: факториал

**Сложность:** простая

**Файл с решением:** [07_recursive_factorial.c](./07_recursive_factorial.c)

## Описание задачи

Реализуйте `unsigned long long factorial(unsigned int n)` через рекурсию (`n! = n * (n-1)!`, `0! = 1`). Напечатайте факториалы 0, 1, 5 и 10.

## Описание решения

Функция сама вызывает себя на меньшем входе. Обязательное условие — базовый случай (здесь `n == 0`), без него возникнет бесконечная рекурсия и переполнение стека.

## Примеры

**Пример 1.**

Вывод:
```
1
1
120
3628800
```
