# 08. static-функция (внутренняя связь)

**Сложность:** простая

**Файл с решением:** [08_static_function.c](./08_static_function.c)

## Описание задачи

Реализуйте `static int square(int x)` — она должна быть видна только в текущем `.c` файле. Используйте её в `main`, выведите квадраты 3 и 7.

## Описание решения

Функция, объявленная как `static` на уровне файла, имеет **внутреннюю связь** (internal linkage): её имя не экспортируется для линковщика, и из других единиц трансляции вызвать её нельзя. Хорошо подходит для приватных утилит модуля и спасает от конфликтов имён.
