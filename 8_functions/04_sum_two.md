# 04. Функция суммы двух чисел

**Сложность:** супер простая

**Файл с решением:** [04_sum_two.c](./04_sum_two.c)

## Описание задачи

Реализуйте функцию `int sum(int a, int b)`, возвращающую сумму. В `main` вычислите и напечатайте сумму 7 и 35.

## Описание решения

Несколько параметров перечисляются через запятую, каждый со своим типом. Возвращаемое значение можно сразу использовать в выражении.
