# 10. Функция, возвращающая структуру

**Сложность:** простая

**Файл с решением:** [10_return_struct.c](./10_return_struct.c)

## Описание задачи

Объявите структуру `Point { int x, y; }`. Реализуйте функцию `struct Point make_point(int x, int y)`, конструирующую и возвращающую такую точку. В `main` выведите координаты.

## Описание решения

В C структуру можно возвращать по значению — компилятор скопирует поля в место присваивания (или, при оптимизациях, применит RVO-подобный приём). Удобно, когда нужно вернуть несколько значений одним пакетом без выделения памяти.
