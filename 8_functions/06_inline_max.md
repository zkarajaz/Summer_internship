# 06. inline-функция максимума

**Сложность:** простая

**Файл с решением:** [06_inline_max.c](./06_inline_max.c)

## Описание задачи

Реализуйте `static inline int imax(int a, int b)`, возвращающую большее из двух чисел. Используйте её в `main`.

## Описание решения

`inline` — это **подсказка** компилятору о возможности встроить тело функции в место вызова, чтобы избежать накладных расходов на вызов. Ключевое слово `static` ограничивает связь файлом, что упрощает использование `inline` в заголовках. Компилятор может проигнорировать подсказку, на результат это не влияет.
