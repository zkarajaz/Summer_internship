# 05. Процедура с побочным эффектом

**Сложность:** супер простая

**Файл с решением:** [05_procedure_greet.c](./05_procedure_greet.c)

## Описание задачи

Реализуйте процедуру (функцию `void`) `greet`, принимающую `const char *name` и печатающую `Hello, <name>!`.

## Описание решения

В C нет ключевого слова `procedure`, его роль играет функция с возвращаемым типом `void`. Аргумент-указатель помечен `const`, чтобы подчеркнуть: функция не модифицирует строку.

## Примеры

**Пример 1.**

Вывод:
```
Hello, Alice!
Hello, Bob!
```
