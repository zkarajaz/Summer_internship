# 03. Функция с одним параметром

**Сложность:** супер простая

**Файл с решением:** [03_one_param.c](./03_one_param.c)

## Описание задачи

Реализуйте функцию `void print_number(int n)`, печатающую переданное число. В `main` вызовите её для нескольких значений.

## Описание решения

Параметры в C передаются по значению — в функцию попадает копия. Изменение `n` внутри функции не повлияет на вызывающий код.

## Примеры

**Пример 1.**

Вывод:
```
1
-5
100
```
