# 01. Функция без параметров и возврата

**Сложность:** супер простая

**Файл с решением:** [01_hello_void.c](./01_hello_void.c)

## Описание задачи

Объявите и определите функцию `print_hello`, которая ничего не принимает и ничего не возвращает (тип `void`). Внутри функции выведите строку `Hello, world!` с переводом строки. В `main` просто вызовите эту функцию.

## Описание решения

Функция типа `void` не возвращает значения и используется ради побочного эффекта (вывод). В прототипе и определении в скобках указывается `void`, чтобы явно подчеркнуть отсутствие параметров.
