# 09. Функция с переменным числом аргументов

**Сложность:** простая

**Файл с решением:** [09_variadic_sum.c](./09_variadic_sum.c)

## Описание задачи

Реализуйте функцию `int sum_all(int count, ...)`, возвращающую сумму `count` целых чисел. Используйте `<stdarg.h>`. В `main` вызовите её с разным числом аргументов.

## Описание решения

Variadic-функции принимают неизвестное на этапе компиляции число аргументов. Через `va_start` / `va_arg` / `va_end` извлекаются переданные значения нужных типов. Первый «именованный» параметр (`count`) используется, чтобы понять, сколько ещё аргументов передано.
