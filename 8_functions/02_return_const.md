# 02. Функция, возвращающая константу

**Сложность:** супер простая

**Файл с решением:** [02_return_const.c](./02_return_const.c)

## Описание задачи

Реализуйте функцию `int get_answer(void)`, возвращающую число 42. В `main` сохраните результат в переменную и выведите его.

## Описание решения

Тип возвращаемого значения указывается перед именем функции. Возврат выполняется оператором `return`.

## Примеры

**Пример 1.**

Вывод:
```
42
```
