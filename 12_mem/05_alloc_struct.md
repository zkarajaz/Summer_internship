# 05. Динамическое выделение структуры

**Сложность:** супер простая

**Файл с решением:** [05_alloc_struct.c](./05_alloc_struct.c)

## Описание задачи

Объявите `struct Point { int x, y; }`. Выделите такую структуру через `malloc`, заполните `(3,4)`, распечатайте, освободите.

## Описание решения

Под структуру выделяется столько байт, сколько нужно типу — обычно записывают `malloc(sizeof *p)`, где `p` — указатель на структуру. Доступ к полям через `->` или `(*p).field`.

## Примеры

**Пример 1.**

Вывод:
```
(3, 4)
```
