# 07. Ловушка: realloc прямо в исходный указатель

**Сложность:** простая

**Файл с решением:** [07_realloc_pitfall.c](./07_realloc_pitfall.c)

## Описание задачи

Покажите **некорректный** паттерн `p = realloc(p, huge_size)`. Если `realloc` вернёт `NULL` (например, при заведомо недостижимом размере, как `(size_t)-1`), мы перезатрём исходный указатель `NULL`-ом и не сможем освободить старый блок — это утечка.

## Описание решения

Никогда не пишите `p = realloc(p, ...)` в продакшен-коде. Всегда сохраняйте новый указатель в отдельную переменную и присваивайте только при успехе.

## Примеры

**Пример 1.**

```
$ ./a.out 2>&1; echo exit=$?
realloc failed; original pointer was overwritten — potential leak
exit=1
```
