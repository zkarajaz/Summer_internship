# 10. free(NULL) — безопасно по стандарту

**Сложность:** простая

**Файл с решением:** [10_free_null_is_ok.c](./10_free_null_is_ok.c)

## Описание задачи

Объявите `int *p = NULL;` и сразу вызовите `free(p)`. Программа должна корректно завершиться. Это удобно: можно не писать вокруг каждого `free` проверку «p != NULL».

## Описание решения

По стандарту C, `free(NULL)` — гарантированно не делает ничего. Поэтому вокруг каждого `free` не нужна проверка `if (p) free(p)`.
