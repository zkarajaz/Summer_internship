# 06. Безопасный realloc через временную переменную

**Сложность:** простая

**Файл с решением:** [06_realloc_safe.c](./06_realloc_safe.c)

## Описание задачи

Выделите буфер на 4 `int`, заполните, потом расширьте до 8 через **временный** указатель: `int *tmp = realloc(buf, 8*sizeof *buf); if (!tmp) { free(buf); ... } else { buf = tmp; }`.

## Описание решения

`realloc` может вернуть `NULL` при неудаче — но **старый блок при этом сохранится**. Если вы напишете `buf = realloc(buf, ...)` и получите `NULL`, вы потеряете указатель на исходный блок и получите утечку. Поэтому используют временную переменную.
