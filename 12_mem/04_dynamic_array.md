# 04. Динамический массив фиксированной длины

**Сложность:** супер простая

**Файл с решением:** [04_dynamic_array.c](./04_dynamic_array.c)

## Описание задачи

Выделите массив на 10 элементов через `malloc(10 * sizeof(int))`. Заполните его значениями `i*i` и распечатайте.

## Описание решения

Идиома `malloc(n * sizeof *p)` (где `p` — целевой указатель) хорошо переносится между типами: если поменять тип `p`, размер посчитается автоматически. Не забудьте `free`.

## Примеры

**Пример 1.**

Вывод:
```
0 1 4 9 16 25 36 49 64 81
```
