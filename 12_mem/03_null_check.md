# 03. Проверка результата malloc на NULL

**Сложность:** супер простая

**Файл с решением:** [03_null_check.c](./03_null_check.c)

## Описание задачи

Выделите блок и **проверьте** возвращаемый указатель на `NULL`. Если `NULL` — выведите сообщение в `stderr` и завершите программу с кодом 1. Иначе — используйте память и освободите.

## Описание решения

`malloc/calloc/realloc` могут вернуть `NULL` при нехватке памяти. Без проверки разыменование `NULL` приводит к падению программы (segfault). Проверка — обязательный паттерн.
