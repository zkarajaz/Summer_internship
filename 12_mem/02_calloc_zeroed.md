# 02. calloc — выделение с обнулением

**Сложность:** супер простая

**Файл с решением:** [02_calloc_zeroed.c](./02_calloc_zeroed.c)

## Описание задачи

Выделите массив из 5 `int` через `calloc`, распечатайте все элементы — они должны быть нулями.

## Описание решения

`calloc(n, size)` выделяет память под `n` объектов размера `size` и **обнуляет** её. Полезно, когда сразу хочется гарантированный «чистый» буфер. У `malloc` такого нет — там память может содержать мусор.
