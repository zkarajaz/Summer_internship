# 04. Имя массива в выражении — это указатель

**Сложность:** супер простая

**Файл с решением:** [04_array_as_pointer.c](./04_array_as_pointer.c)

## Описание задачи

Объявите `int a[3] = {10,20,30}`. Распечатайте `a[0]` и `*a` — должны быть равны. То же самое для `a[1]` и `*(a+1)`.

## Описание решения

В большинстве выражений имя массива неявно превращается в указатель на его первый элемент: `a` ↔ `&a[0]`. Поэтому `a[i]` эквивалентно `*(a+i)`.

## Примеры

**Пример 1.**

Вывод:
```
a[0]=10 *a=10
a[1]=20 *(a+1)=20
```
