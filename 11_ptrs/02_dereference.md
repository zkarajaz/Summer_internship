# 02. Разыменование указателя

**Сложность:** супер простая

**Файл с решением:** [02_dereference.c](./02_dereference.c)

## Описание задачи

Объявите `int x = 10`, `int *p = &x`. Распечатайте `*p` — должно напечататься 10.

## Описание решения

`*p` — оператор разыменования: «значение, на которое указывает p». Это второй базовый оператор работы с указателями (вместе с `&`).

## Примеры

**Пример 1.**

Вывод:
```
10
```
