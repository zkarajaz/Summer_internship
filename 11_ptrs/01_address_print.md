# 01. Получить адрес переменной

**Сложность:** супер простая

**Файл с решением:** [01_address_print.c](./01_address_print.c)

## Описание задачи

Объявите `int x = 7;` и распечатайте адрес `x` через `&x` форматом `%p`.

## Описание решения

Оператор `&` возвращает адрес объекта в памяти. Тип адреса — указатель (`int *`). Формат `%p` выводит указатель в реализационно-зависимом виде (обычно hex). Сам адрес от запуска к запуску может меняться — это нормально.

## Примеры

**Пример 1.**

Вывод:
```
x=7, &x=0x7ffe1a2b3c4d   ← конкретный адрес зависит от запуска
```
