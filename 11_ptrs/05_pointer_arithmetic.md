# 05. Простая арифметика указателей

**Сложность:** супер простая

**Файл с решением:** [05_pointer_arithmetic.c](./05_pointer_arithmetic.c)

## Описание задачи

Объявите массив `int a[5] = {1,2,3,4,5}`. С помощью указателя `p = a` пройдитесь по массиву и распечатайте все элементы, инкрементируя `p`.

## Описание решения

Прибавление целого к указателю двигает его на N **элементов** (а не байт). Поэтому `p+1` для `int*` — это адрес следующего `int`. Так удобно проходить массив циклом.

## Примеры

**Пример 1.**

Вывод:
```
1 2 3 4 5
```
