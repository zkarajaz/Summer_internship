# 03. Изменение значения через указатель

**Сложность:** супер простая

**Файл с решением:** [03_modify_via_ptr.c](./03_modify_via_ptr.c)

## Описание задачи

Через указатель `p` поменяйте значение переменной `x` с 0 на 99. Распечатайте `x` до и после.

## Описание решения

Через указатель можно не только читать, но и писать: `*p = ...`. Это основа того, как функция может модифицировать аргумент: ей передают указатель.
